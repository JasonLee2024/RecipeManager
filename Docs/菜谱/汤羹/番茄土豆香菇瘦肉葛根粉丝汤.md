# 番茄土豆香菇瘦肉葛根粉丝汤

推荐分类：`汤羹`  
推荐标签：`家常菜`、`下饭菜`、`一锅出`、`饱腹`、`场景/工作日`、`食材/加工与其他/米面主食/葛根粉条`、`食材/植物/蔬菜/茄果/番茄`、`食材/植物/蔬菜/根茎/土豆`、`食材/植物/蔬菜/菌菇/香菇`、`食材/植物/蔬菜/叶菜/上海青`、`食材/动物/肉类/猪`、`口味/酸甜`、`口味/咸鲜`

有了葛根粉丝和瘦肉，这道菜可以直接升级为**一锅出的大满足版下饭汤羹**——番茄酸香开胃，土豆绵软增稠，香菇提鲜，瘦肉嫩滑，葛根粉丝爽滑吸汁，最后加上上海青的清甜。整锅浇在米饭上，每一口都是「米饭杀手」。

全国各地家常炖煮思路，**地域归属不唯一**，故不单列八大菜系等地域标签。

## 食材清单（2-3人份）

- **番茄** 2个（去皮切块）
- **土豆** 1个（切小丁）
- **香菇** 5-6朵（切片）
- **上海青** 2-3棵（梗叶分开）
- **瘦肉** 150g（猪里脊或前腿肉，切薄片或细条）
- **葛根粉丝** 1小把（约50g，提前用温水泡软剪短）
- **蒜末、葱花** 适量
- **调味**：食用油、盐、生抽、老抽（可选，调色）、白胡椒粉、糖、料酒、玉米淀粉

可选：

- **番茄酱** 1勺（炒底料时，汤色更红、味更浓）
- **水淀粉** 少许（出锅前勾薄芡，羹感更强）

## 做法步骤

### 1. 处理瘦肉

- 瘦肉切薄片（逆纹切更嫩），加**1勺生抽、半勺料酒、少许白胡椒粉、半勺玉米淀粉、1勺清水**，抓匀至水分吸收，最后淋半勺油封住，腌10分钟。

### 2. 准备其他食材

- 葛根粉丝用温水泡10分钟至软，沥干剪几刀，方便入口。
- 番茄切小块，土豆切小丁（越小越容易煮化），香菇切片，上海青切段。

### 3. 炒底料（关键步骤）

- 热锅少油，中火爆香蒜末。
- 下番茄块，边炒边压，炒至完全软烂出红油（约2-3分钟）。
- 加1勺番茄酱（可选，更浓郁）和半勺糖，炒匀。
- 下香菇片和土豆丁，翻炒1分钟，让香菇吸足番茄汁。

### 4. 熬煮汤底

- 倒入**热开水**约600-800ml（想多汤汁拌饭就多加），大火烧开。
- 加1勺生抽、半勺老抽（只为颜色，可不加）、适量盐和少许糖。
- 转中火煮8-10分钟，直到土豆丁边缘开始粉化、汤汁变自然浓稠。**期间用铲子轻压几下土豆丁**，加速出沙。

### 5. 滑入瘦肉和粉丝

- 转小火，将腌好的瘦肉一片片展开下锅，不要搅动，静置10秒让蛋白凝固，再用筷子轻轻划散。
- 下入泡软的葛根粉丝，转中火煮2-3分钟，粉丝变透明即可。

### 6. 下青菜并收尾

- 先下上海青的**梗**烫30秒，再下**叶子**烫变色就关火（保持翠绿脆口）。
- 撒白胡椒粉和葱花，尝味补盐。

### 7. 出锅拌饭

- 直接连汤带菜浇在热米饭上。如果喜欢更浓厚的羹状，可以在下粉丝前淋入**少许水淀粉**勾薄芡。

## 设计巧思 — 为什么这样特别下饭？

| 食材 | 作用 |
|------|------|
| **番茄+土豆** | 番茄提供酸香基底，土豆部分化成淀粉，让汤汁天然浓稠，挂在米饭上。 |
| **香菇** | 释放鸟苷酸，和番茄的谷氨酸协同增鲜，比纯肉汤更有层次。 |
| **瘦肉** | 用淀粉浆过，嫩滑不柴，提供肉香和饱腹感。 |
| **葛根粉丝** | 比普通粉丝更爽滑、不易糊烂，吸满了酸甜汤汁，嗦一口非常过瘾。 |
| **上海青** | 最后放入，保持清脆口感和鲜绿色，解腻又清爽。 |

## 实用小贴士

1. **瘦肉不老的诀窍**：腌的时候抓入少量清水和淀粉，最后淋油封住；下锅时汤要微沸不滚，滑入后别马上搅动。
2. **土豆切多小？** 1厘米见方以下，煮10分钟必定沙软。如果不喜欢土豆完全化掉，可以留一半大块后下。
3. **粉丝别煮太久**：葛根粉丝泡软后煮2-3分钟足够，煮久了会断成小段，失去滑溜口感。
4. **没有葛根粉丝怎么办？** 用红薯粉丝或龙口粉丝替代，但红薯粉丝需多煮一会儿，龙口粉丝无需泡太久。
5. **一次多做点**：这道菜隔夜后风味更融合（土豆淀粉会让汤汁更浓），第二天热一热拌饭或拌面都极好。

## 味道描述

舀一勺汤淋在米饭上，米粒立刻染成橙红色。入口先是番茄的明亮酸香，接着是土豆融化带来的绵密口感，香菇和瘦肉的咸鲜慢慢浮现，最后咬到爽脆的上海青和滑溜的葛根粉丝。粉丝挂满了汤汁，吸溜一口，酸、鲜、滑、脆同时在嘴里炸开。米饭不知不觉就见了底。

这道菜成本不高，但营养均衡（蔬菜+菌菇+肉+淀粉类+粉丝），一锅解决一顿饭，特别适合想偷懒又想吃得满足的日子。
