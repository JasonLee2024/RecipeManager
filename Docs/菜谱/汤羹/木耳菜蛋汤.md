# 木耳菜蛋汤

推荐分类：`汤羹`  
推荐标签：`快手菜`、`家常菜`、`食材/植物/蔬菜/叶菜/木耳菜`、`食材/动物/蛋类`、`口味/清淡`

蛋花成形后再下木耳菜，短时煮沸即可出锅，汤鲜菜仍带点脆感。**家常快手汤，地域归属不唯一。**

## 食材

- **木耳菜**：约 200 g，洗净，切掉较老根部。
- **鸡蛋**：2 个，打散。
- **干木耳**：少许，提前泡发，撕成小朵。
- **姜丝**：少许。
- **清水或高汤**：适量。
- **盐、香油**：少许。

## 做法

1. 鸡蛋打散；干木耳泡发撕小朵；木耳菜洗净。
2. 锅中烧开水或高汤，下姜丝与木耳煮 **2～3 分钟**。
3. 转中小火，缓缓淋入蛋液，待形成蛋花。
4. **立即**下木耳菜，煮至变色变软，加盐、几滴香油出锅。**木耳菜入锅后全程不超过约 1 分钟**，久煮易烂、失脆。

## 小贴士

- 木耳菜最后下锅、短时加热是口感关键。
