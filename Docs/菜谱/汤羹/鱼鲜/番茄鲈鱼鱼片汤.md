# 番茄鲈鱼鱼片汤

推荐分类：`汤羹`  
推荐标签：`家常菜`、`口味/清淡`、`场景/工作日`、`食材/动物/海鲜/鲈鱼`、`口味/酸甜`

片取鲈鱼柳做鱼片，番茄熬汤底，酸甜适口；适合不想吃整鱼或给老人孩子食用。

## 食材

- **鲈鱼**：1 条，片下两侧净肉。
- **番茄**：2～3 个中等大小，切块。
- **蛋清**：1 个份（上浆用）。
- **淀粉**：1～2 茶匙。
- **食盐、白糖**：适量。
- **生姜**：少许切丝或末。
- **植物油**：适量。
- **清水或高汤**：约 600～800 ml。
- **醋**：少许（起锅前提香，可选）。
- **葱花**：少许。

## 做法

1. 鱼肉斜刀片成薄片，用盐抓黏，加蛋清与淀粉抓匀上浆，静置 **10 分钟**。
2. 热锅少油，炒香姜丝，下番茄块中火炒出汁，加糖与盐调味，加水或高汤煮开。
3. 汤色红亮后转小火保持微沸，将鱼片**一片片分散下入**，先勿搅动。
4. 待鱼片**变白定型**后，再轻轻推散，烫煮约 **1 分钟**至熟透。
5. 淋少许醋（可选），撒葱花即可。

## 小贴士

- 鱼片下锅后**不要马上搅动**，定型后再推，不易碎。
- 上浆前鱼肉用厨房纸**吸干**，糊浆更牢。
- 番茄酸度不足可加少许番茄酱辅助（按喜好）。
