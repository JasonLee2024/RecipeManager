# 鲈鱼豆腐汤

推荐分类：`汤羹`  
推荐标签：`家常菜`、`口味/清淡`、`场景/工作日`、`食材/动物/海鲜/鲈鱼`、`口味/咸鲜`

鱼先煎香再冲**开水**，汤色易呈乳白；豆腐吸收鲜味，适合全家。

## 食材

- **鲈鱼**：1 条（也可切段），处理干净。
- **豆腐**：嫩豆腐或北豆腐 300～400 g，切块。
- **生姜**：数片。
- **大葱**：少许切段。
- **料酒**：1 汤匙（可选）。
- **食盐、白胡椒粉**：适量。
- **植物油**：煎鱼用量。
- **开水**：约 800～1200 ml（须**刚沸腾**）。
- **葱花**：少许。

## 做法

1. 鱼身擦干，两面可抹少许盐；热锅凉油，中火将鱼**两面煎至金黄**。
2. 下姜片、葱段煸香，烹料酒（可选）。
3. 冲入**滚烫开水**，**大火**煮 **5 分钟左右**，汤色转白。
4. 下豆腐块，转中火续煮 **5～8 分钟**。
5. 加盐、白胡椒粉调味，撒葱花出锅。

## 小贴士

- **开水**且保持大火翻滚一段时间，乳白汤更稳定。
- 煎鱼前**吸干水分**，皮不破、汤更清亮。
- 海鲈鱼注意控盐。
