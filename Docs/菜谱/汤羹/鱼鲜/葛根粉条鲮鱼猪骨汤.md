# 葛根粉条鲮鱼猪骨汤

推荐分类：`汤羹`  
推荐标签：`家常菜`、`经典菜`、`粤菜`、`食材/加工与其他/米面主食/葛根粉条`、`口味/咸鲜`

鲮鱼、猪骨与葛根粉条同煲，汤色清鲜、**清甜回甘**；按**粤式**家常煲汤骨架，宜文火慢滚。

## 食材

- **猪骨**（筒骨或扇骨）：400～500 g，焯水洗净。
- **鲮鱼**（鲜鱼一条或鱼干适量）：与猪骨比例按家庭习惯；鲜鱼可先煎香再煲。
- **葛根粉条**：干约 50～80 g，泡软备用。
- **生姜**：1 大块拍松；**蜜枣或陈皮**：1～2 颗 / 1 小片（可选，增甘香）。
- **清水**：足量（约 1.5～2 L，按锅具调整）。
- **食盐**：起锅前按口味添加。

## 做法

1. 猪骨冷水下锅煮沸撇沫，捞出冲洗；鲜鲮鱼可煎至两面微黄（可选，汤更白更香）。
2. 汤煲中加足清水、猪骨、姜（及蜜枣、陈皮），大火烧开转小火煲 **1～1.5 小时**。
3. 下鲮鱼（若用鱼干可与骨同下；鲜鱼宜后下防散），续煲 **20～30 分钟**。
4. 下泡软的葛根粉条，煮 **8～12 分钟**至粉条透明入味，加盐调味即可。

## 小贴士

- 鲮鱼刺多，可选用**鲮鱼滑**或布袋包鱼袋煲汤。
- 粉条后下，避免久煲浑汤；汤宜清鲜，少厚重调料。
