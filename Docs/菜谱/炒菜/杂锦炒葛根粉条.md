# 杂锦炒葛根粉条

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`快手菜`、`食材/加工与其他/米面主食/葛根粉条`、`食材/动物/肉类/牛`、`口味/咸鲜`

牛肉、彩椒、洋葱与葛根粉条同炒，**镬气足、配色亮**，粉条吸汁后仍弹。

## 食材

- **葛根粉条**：干约 80～100 g。
- **牛肉**：150～200 g，切条或薄片，少许生抽、料酒、淀粉抓匀腌 10 分钟。
- **洋葱**：半个，切丝。
- **彩椒**：红或黄半个，切条。
- **大蒜**：2 瓣，切片。
- **生抽**：1.5 汤匙。
- **蚝油**：1 汤匙（可选）。
- **料酒**：1 茶匙。
- **食盐、白糖**：少许。
- **植物油**：适量。

## 做法

1. 粉条按包装泡软，沸水煮至无硬芯，捞出沥干，可少油拌匀防粘。
2. 热锅宽油，大火滑炒牛肉至变色盛出。
3. 底油爆香蒜片，下洋葱、彩椒翻炒至断生。
4. 倒入粉条与牛肉，加生抽、蚝油、料酒、糖，大火翻匀；按口味补盐，炒匀出锅。

## 小贴士

- 牛肉宜逆纹切；锅要热、动作要快，避免牛肉老。
- 粉条已熟，入锅以**翻匀挂味**为主，不宜久炒以免断碎。
