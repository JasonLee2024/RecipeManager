# 豆豉蒜蓉炒苦瓜

推荐分类：`炒菜`  
推荐标签：`经典菜`、`家常菜`、`粤菜`

豆豉与蒜蓉咸香浓郁，能压住苦味，非常下饭。属**粤菜**家常小炒风格。通用去苦技巧见：`Docs/菜谱/炒菜/苦瓜去苦与经典做法.md`。

## 食材

- 苦瓜 1 根
- 豆豉 1 小把（略冲洗后切碎，减轻过咸与杂质）
- 大蒜 半头（切末，量宜多一些）
- 小米辣 1～2 根（可选，切圈）
- 白糖 半小勺（中和苦味）
- 生抽 少许
- 植物油 适量

## 做法

1. 苦瓜剖开刮净白瓤与白膜，切薄片；水烧开加一小勺盐、几滴油，下苦瓜片焯烫约 30 秒，捞出过凉水或冰水，沥干备用。
2. 热锅放油，**小火**下豆豉碎、蒜末、小米辣，煸至蒜香、豆豉出味（注意别炒糊）。
3. 转大火，倒入苦瓜片快速翻炒约 1 分钟。
4. 加入白糖、少许生抽炒匀；豆豉本身偏咸，一般**不必再加盐**，口重可略补盐。
5. 炒匀后立刻出锅，保持苦瓜爽脆。

## 小贴士

- 豆豉先冲洗再切碎，咸度更稳；生抽少放，以免发黑、过咸。
- 焯苦瓜加盐油可保色；过凉可增脆、抑苦。
