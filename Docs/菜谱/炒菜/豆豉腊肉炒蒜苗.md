# 豆豉腊肉炒蒜苗

推荐分类：`炒菜`  
推荐标签：`下饭菜`、`家常菜`、`待客菜`

这道菜以腊肉自带油香和豆豉咸鲜为主，蒜苗提香解腻，适合配米饭。

## 食材

- 腊肉或腊肠 200～250 g（切薄片）
- 蒜苗 250 g（蒜白与蒜绿分开切段）
- 豆豉 1 大勺（可先冲洗、略浸泡）
- 大蒜 2 瓣（切末）
- 生姜 1 小块（切末）
- 生抽 少许（按需）
- 白糖 少许

## 做法

1. 腊肉或腊肠切薄片；蒜苗分开蒜白与蒜绿，豆豉处理后沥干。
2. 锅中少油或不放油，小火下腊肉煸至出油、边缘微卷。
3. 利用锅中油脂炒香蒜末、姜末和豆豉，炒出豉香。
4. 先下蒜白大火快炒约20秒，再下蒜绿继续快炒至断生。
5. 视咸度补少量生抽和白糖提鲜，翻匀后出锅。

## 小贴士

- 腊味和豆豉都偏咸，通常无需再加盐。
- 想更清爽可加几片青椒同炒。
