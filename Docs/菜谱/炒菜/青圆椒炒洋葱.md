# 青圆椒炒洋葱

推荐分类：`炒菜`  
推荐标签：`快手菜`、`家常菜`、`经典菜`、`场景/工作日`、`食材/植物/蔬菜/茄果/青椒`、`食材/植物/蔬菜/根茎/洋葱`、`口味/咸鲜`

洋葱甜香与青椒清香组合，口感脆爽，适合平衡烧炖类主菜的浓郁感。各地家庭常见做法，**地域归属不唯一**。可配鸡蛋或五花肉片同炒。

## 食材

- **青圆椒**：适量，去蒂去籽，切**滚刀块**或**细丝**。
- **洋葱**：适量，去皮，切成与青椒**大小相近的块**。
- **盐**：适量。
- **白糖**：少许。
- **生抽**：少许。
- **植物油**：适量。
- **可选**：鸡蛋 2 个；或五花肉片少许煸出猪油。

## 做法

1. 热锅冷油，先下洋葱**大火**煸炒出香味，炒至边缘微微透明。
2. 下青椒块，快速翻炒 **20～30 秒**，保持清脆与翠绿。
3. 用盐、一点点白糖和生抽调味，炒匀出锅。

## 小贴士

- 青椒、洋葱**不宜过熟**，保留一点脆感，与软糯的烧粉条、土豆类主菜层次更分明。
- 若加蛋：可先炒散盛起，再按上述步骤炒蔬菜，最后合炒。
