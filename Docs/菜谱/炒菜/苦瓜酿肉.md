# 苦瓜酿肉

推荐分类：`炒菜`  
推荐标签：`宴客`、`家常菜`

肉馅与汤汁包裹苦瓜，苦味更柔和。通用去苦技巧见：`Docs/菜谱/炒菜/专题_苦瓜去苦与经典做法.md`。

## 食材

- 苦瓜 1 根
- 猪肉末 150 g
- 干香菇 2～3 朵（温水泡发，切丁，拌入肉末；也可用鲜香菇或适量虾滑替代一部分肉）
- 姜 1 小块、小葱 2 根（切末）
- 枸杞 少许（点缀，可选）
- 生抽、蚝油、白胡椒粉、白糖、淀粉 各适量（腌肉用）
- 水淀粉 少许（勾芡用）
- 清水 小半碗（调芡用）

## 做法

1. 苦瓜洗净，切成约 2～3 cm 厚的圈，用勺子挖去内瓤与白膜，内壁尽量刮净。
2. 肉末加葱姜末、生抽、蚝油、白胡椒粉、少许糖、淀粉，朝同一方向搅打至发黏上劲；拌入香菇丁（或虾滑）搅匀。
3. 将肉馅填入苦瓜圈，**压实抹平**表面，码入深盘；可放几粒枸杞在肉馅上点缀。
4. 蒸锅水烧开后放入盘子，**中火**蒸 8～10 分钟（圈厚则略延长时间）；至肉馅熟透、苦瓜可用筷子戳透即可。
5. 若怕苦，可将盘中蒸出的汤汁**倒掉一部分**；其余汤汁倒入锅中，补少许生抽与清水烧开，勾薄芡，淋回苦瓜酿肉上即可上桌。

## 小贴士

- 苦瓜圈厚度尽量一致，成熟度才均匀。
- 芡汁宜薄，突出清鲜；蒸汁偏苦时可多倒少留。
