# 蒜蓉蚝油上海青

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`下饭菜`、`食材/植物/蔬菜/叶菜/上海青`、`口味/咸鲜`

先焯至断生保持翠绿，再浇**蒜蓉蚝油芡汁**，比清炒更浓郁。浇汁装盘的做法在**粤式**酒楼与家常餐桌都很常见。

## 食材

- **上海青**：400～500 g，整棵或对半剖开洗净。
- **大蒜**：1 整头或更多，切**蒜蓉**（分量足才香）。
- **蚝油**：1.5～2 汤匙。
- **盐**：焯水用少许；酱汁中按口味补少许。
- **食用油**：适量；焯水时滴几滴有助保色。
- **清水或水淀粉**：2～3 汤匙（清水）或水淀粉少许（喜稠汁用）。

## 做法

1. **焯水**：水烧开，加**几滴油**和**少许盐**，下上海青，**焯 1～2 分钟**至梗软仍脆、捞出沥干，**装盘**。
2. **炒蒜蓉蚝油**：锅中留底油，**小火**下蒜蓉煸香，加蚝油与少量清水（或水淀粉）煮至**略稠**。
3. **浇汁**：将酱汁均匀浇在摆好的上海青上即可。

## 小贴士

- 焯水时间按株型调整；捞出可**轻压沥水**，避免盘中汪汤。
- 蒜蓉务必**小火**，焦苦会影响整道菜。
