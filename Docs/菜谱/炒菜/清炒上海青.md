# 清炒上海青

推荐分类：`炒菜`  
推荐标签：`快手菜`、`家常菜`、`经典菜`、`场景/工作日`、`食材/植物/蔬菜/叶菜/上海青`、`口味/咸鲜`

大火快炒是品尝上海青**清甜原味**最直接的做法。要点是**梗叶分下锅**，梗先叶后，全程猛火、短时长，避免软烂出水。

## 食材

- **上海青**：400～500 g，洗净沥干；株型大可**梗叶切开分放**。
- **大蒜**：2～3 瓣，切末。
- **盐**：适量。
- **食用油**：适量（略多于素炒白菜亦可）。
- **蚝油、鸡精**（可选）：各少许，起锅前提鲜。

## 做法

1. **梗叶处理**：大棵上海青将**菜梗切段**、**菜叶另放**；小棵可整株或对半剖开。
2. **爆香**：锅烧热倒油，**中火**下蒜末煸香，勿炒糊。
3. **快炒**：转**大火**，**先下菜梗**快速翻炒约 20～40 秒至边缘略透明。
4. **下菜叶**：倒入菜叶，大火翻匀至叶软仍挺。
5. **调味出锅**：加盐（及可选蚝油、鸡精）快速翻匀，**立即出锅**。

## 小贴士

- 洗后尽量**甩干或沥水**，减少入锅爆油与出水。
- 喜镬气可锅温略高再下菜；全程控制在**两三分钟内**口感最佳。
