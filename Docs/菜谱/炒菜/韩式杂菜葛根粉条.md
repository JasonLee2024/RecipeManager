# 韩式杂菜葛根粉条

推荐分类：`炒菜`  
推荐标签：`家常菜`、`快手菜`、`食材/加工与其他/米面主食/葛根粉条`、`口味/咸鲜`

以韩式杂菜（Japchae）为灵感：煮熟的葛根粉条与**牛肉丝、洋葱、彩椒、菌菇**等用酱油、芝麻油翻炒，咸鲜带芝麻香；喜辣可加少许韩式辣酱。

## 食材

- **葛根粉条**：干约 80～100 g。
- **牛肉丝**：100～120 g，以少许生抽、糖、淀粉腌 10 分钟。
- **洋葱**：1/4 个，切丝。
- **彩椒**：适量，切丝。
- **金针菇或香菇丝**：一小把。
- **菠菜或油菜**：数棵，焯烫切段（可选）。
- **大蒜**：1～2 瓣，切末。
- **生抽**：1.5～2 汤匙。
- **芝麻油**：1～1.5 汤匙。
- **白糖**：1/2～1 茶匙。
- **韩式辣酱**（可选）：1/2～1 茶匙。
- **熟白芝麻**：少许。
- **植物油**：适量。

## 做法

1. 粉条泡软后煮熟沥干，淋少许芝麻油拌匀防粘。
2. 分别快炒或焯熟配菜（菠菜焯水挤干），牛肉丝大火炒至变色盛出。
3. 锅中补油，炒香蒜末，下洋葱、彩椒、菌菇炒软。
4. 下粉条，加生抽、糖、可选辣酱，大火翻匀；回锅牛肉与蔬菜，淋剩余芝麻油，撒芝麻出锅。

## 小贴士

- 传统杂菜常用红薯粉条；葛根粉条更弹，酱汁宜略少，避免汪汤。
- 蔬菜种类可按冰箱库存替换，保持**先分别处理再合拌**更易控火候。
