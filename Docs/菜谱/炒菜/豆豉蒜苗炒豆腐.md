# 豆豉蒜苗炒豆腐

推荐分类：`炒菜`  
推荐标签：`下饭菜`、`家常菜`、`减脂菜`

豆腐吸收豆豉与蒜苗的香味后非常入味，整体比肉版更清爽，也很下饭。

## 食材

- 老豆腐 300 g（切小块）
- 蒜苗 200～250 g（蒜白与蒜绿分开）
- 豆豉 1 大勺
- 大蒜 2 瓣（切末）
- 生抽 1 小勺
- 白糖 少许
- 盐 少许（按需）
- 植物油 适量

## 做法

1. 豆腐切块后下锅煎至两面金黄盛出；蒜苗分开切蒜白和蒜绿。
2. 锅中留底油，小火炒香蒜末与豆豉。
3. 转大火先下蒜白快炒约20秒，再下蒜绿继续快炒。
4. 倒回豆腐块，淋入生抽翻匀，加少许白糖提鲜。
5. 尝味后按需补盐，炒至蒜苗断生即可出锅。

## 小贴士

- 老豆腐更耐炒，不易碎。
- 豆腐下锅后尽量翻拌轻一些，保持块形完整。
