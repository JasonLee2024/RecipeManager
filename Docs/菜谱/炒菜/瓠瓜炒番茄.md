# 瓠瓜炒番茄

推荐分类：`炒菜`  
推荐标签：`快手菜`、`家常菜`

清爽开胃，番茄的酸甜把瓠瓜的清甜托出来。蒜末最后放，香味更亮。

## 食材

- 瓠瓜 约 300-400 g（去皮切片）
- 番茄 1-2 个（切块）
- 大蒜 2-3 瓣（切末）
- 青椒 少许（可选）
- 盐 适量
- 食用油 适量

## 做法

1. 瓠瓜去皮切片；番茄切块。瓠瓜偏老则挖掉籽瓤。
2. 热锅下油，先下瓠瓜中火翻炒 1-2 分钟至略出水、变软。
3. 下番茄（和可选的青椒）翻炒，番茄软烂出汁后尝味。
4. 需要更“酱”一点可加一两勺热水略焖；最后下蒜末翻几下，加盐调味出锅。

## 小贴士

- 瓠瓜本身出水多，通常不必额外加水；想做焖口感再少量补水即可。
- **试苦**：若瓠瓜有明显苦味请直接丢弃整根。
