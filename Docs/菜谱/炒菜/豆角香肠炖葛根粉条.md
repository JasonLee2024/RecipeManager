# 豆角香肠炖葛根粉条

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`经典菜`、`食材/加工与其他/米面主食/葛根粉条`、`食材/加工与其他/加工肉制品/香肠`、`口味/咸鲜`

**干豆角**（或鲜豆角）与香肠、葛根粉条同炖，咸香家常，粉条吸饱肉香。

## 食材

- **葛根粉条**：干约 80～100 g。
- **干豆角**：50～80 g，提前温水泡软切段（或鲜豆角 200 g 切段）。
- **香肠**：1～2 根，切片。
- **五花肉片**（可选）：80 g，增脂香。
- **大蒜**：3 瓣；**八角** 1 颗（可选）。
- **生抽**：2 汤匙；**老抽**：1/2 茶匙（上色）。
- **食盐、白糖**：适量。
- **清水**：约 500～700 ml。
- **植物油**：少许。

## 做法

1. 葛根粉条泡软备用；干豆角泡软切段。
2. 锅中少油，煸香蒜片、八角，下五花肉片（若有）与香肠炒出油香。
3. 下豆角翻炒，加生抽、老抽、糖，倒入清水烧开，中小火炖 **15～20 分钟**至豆角软烂入味。
4. 下泡软的粉条，翻匀浸在汤中，再炖 **8～10 分钟**收汁；按口味补盐出锅。

## 小贴士

- 香肠偏咸时减少生抽与盐。
- 鲜豆角需炖更久或先焯至半熟再与粉条同炖，避免豆角未熟。
