这份总览用于快速理解豆豉炒肉在四川常见的两种路线：回锅派与生爆派。

### 两派对比一览

| 维度 | 回锅派（豆豉炒肉/回锅肉） | 生爆派（豆豉盐煎肉） |
| :--- | :--- | :--- |
| 核心处理 | 先煮后炒 | 生肉直接爆炒 |
| 口感 | 软糯Q弹、肥而不腻 | 干香酥嫩、更有嚼劲 |
| 风味重心 | 豉香 + 酱香（豆瓣） | 豉香主导、咸鲜干香 |
| 肉类选择 | 常用带皮五花或二刀肉 | 常用去皮后腿肉或五花 |
| 技术关键 | 煮透晾凉后切薄，炒到灯盏窝 | 油温与火候控制，快速生爆 |
| 适合场景 | 家庭经典、口感层次丰富 | 快手下饭、风味更直接 |

### 对应文档

- 回锅派：`Docs/菜谱/炒菜/豆豉炒肉.md`
- 生爆派：`Docs/菜谱/炒菜/豆豉盐煎肉.md`

### 选做建议

- 想要软糯与油脂香：优先回锅派。
- 想要干香与咀嚼感：优先生爆派。
- 两派都建议配米饭，且注意豆豉、豆瓣酱咸度，通常无需额外加盐。
