### 共同底层原则

所有菜的灵魂起点都一致：**豆瓣酱先剁细，再低油温小火慢煸至红亮酥香**。  
这一步决定了后续菜品的色泽、酱香与稳定风味。

### 下饭菜（家常快手）

**1）麻婆豆腐**
- 核心要点：豆腐先热盐水浸泡或轻焯，减少破碎并提前入底味。
- 关键步骤：牛肉末先煸酥；豆瓣酱低温煸红后再烧豆腐；分次勾芡增强裹汁感。
- 对应文档：`Docs/菜谱/炒菜/麻婆豆腐.md`

**2）回锅肉**
- 核心要点：肉片先煮后切薄，再中火煸至“灯盏窝”吐油卷曲。
- 关键步骤：利用锅底油低温煸豆瓣酱出红油；蒜苗最后大火快炒，锅边点醋提香。
- 对应文档：`Docs/菜谱/炒菜/回锅肉.md`

### 待客菜（上桌有排面）

**1）水煮牛肉 / 水煮鱼**
- 核心要点：分两段用油——底油负责“煸红煸香”，响油负责“瞬时爆香”。
- 关键步骤：先做红汤再浇碗，最后热油浇辣椒花椒激香，形成高识别度上桌效果。
- 对应文档：`Docs/菜谱/炒菜/水煮牛肉.md`、`Docs/菜谱/炒菜/水煮鱼.md`

**2）豆瓣鲫鱼 / 豆瓣鲤鱼**
- 核心要点：整鱼先煎干身定型，再入红汤慢烧，最后勾芡淋汁提亮。
- 关键步骤：糖醋分阶段加入（烧制中融合 + 起锅前补少量生醋）以平衡酱香与鲜味。
- 对应文档：`Docs/菜谱/炒菜/豆瓣鲫鱼.md`、`Docs/菜谱/炒菜/豆瓣鲤鱼.md`

### 选菜建议

- **赶时间且要稳妥下饭**：优先麻婆豆腐、回锅肉。
- **需要上桌仪式感**：优先水煮牛肉/水煮鱼。
- **想做整鱼主菜**：优先豆瓣鲫鱼/豆瓣鲤鱼。
- **整体调味原则**：豆瓣酱与豆豉含盐高，先尝味再补盐，避免过咸。
