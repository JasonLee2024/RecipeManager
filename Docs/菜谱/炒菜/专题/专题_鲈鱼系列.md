# 鲈鱼系列

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`高蛋白菜`、`食材/动物/海鲜/鲈鱼`

鲈鱼刺少肉嫩，做法从清蒸到红烧、煎焗、煮汤皆可。本文做**系列导航与共用要点**，具体火候与配料以各独立菜谱为准。

## 二、共用要点（跨菜谱）

- **擦干再下锅**：煎、蒸、焗前用厨房纸吸干表面水分，利于去腥、脆皮与不溅油。
- **海鲈鱼减盐**：若选购海鲈鱼，自体咸味较重，腌料与酱油类宜酌情减量。
- **鱼片勿早搅**：片鱼做汤时，鱼片下锅后待定型再轻推，不易碎。

## 四、今晚做哪道？

- **想最快吃到本味**：清蒸鲈鱼；喜酱香选红烧鲈鱼或砂锅焗鲈鱼。  
- **想换口味或夏天开胃**：柠香鲈鱼；想喝汤选鲈鱼豆腐汤或番茄鲈鱼鱼片汤。  
- **想做西餐感或佐简餐**：香煎鲈鱼。
