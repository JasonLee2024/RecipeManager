# 土豆肉丝三做法

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`场景/工作日`、`食材/动物/肉类/猪`、`食材/植物/蔬菜/根茎/土豆`、`口味/清淡`、`口味/酸辣`、`口味/咸鲜`

土豆与肉丝是经典组合，做法灵活，口味可从清淡做到浓郁。下文汇总三种常见家常风味：**青椒清淡版**、**酸辣开胃版**、**红烧酱香版**。文尾通用技巧建议先读再做。

三种做法均为全国各地家常小炒常见组合，**地域归属不唯一**，故不单列八大菜系等地域标签。

## 一、青椒土豆肉丝（清淡原味）

适合日常，配菜简单，老少皆宜。

**核心要点**：肉丝与土豆丝**分炒**，最后**大火快炒立刻出锅**，保证肉嫩、薯丝爽脆、色泽清爽。

### 食材

- **土豆**：1～2 个，切细丝。
- **猪瘦肉**：约 150 g，切丝。
- **青椒**：1～2 个，切丝。
- **生姜、大蒜**：切末。
- **生抽、料酒、淀粉、食盐、白糖**：适量。
- **植物油**：适量。

### 步骤

1. **腌制**：肉丝加少许生抽、料酒、淀粉抓匀腌约 10 分钟，最后淋少许食用油拌匀锁水。
2. **土豆丝**：切丝后入**冷水**浸泡，洗去表面淀粉；用时沥干。青椒切丝备用。
3. **炒肉丝**：热锅凉油，下肉丝快速滑散，**变色即盛出**。
4. **炒土豆丝**：用余油爆香姜蒜末，大火下土豆丝快炒 1～2 分钟至断生。
5. **合炒**：下青椒丝，倒回肉丝，加约 1 勺生抽、少许盐和糖，大火翻匀即可出锅。

## 二、酸辣土豆肉丝（开胃辣味）

偏重口与开胃，**酸、辣、香**是灵魂。

### 食材

- **土豆**：1～2 个；**猪瘦肉**：约 150 g。
- **干辣椒 / 小米辣 / 泡椒**：按嗜辣程度选用。
- **大蒜**：切末；**花椒**：少许（可选）。
- **醋**：白醋或香醋；**生抽、蚝油、食盐、白糖**：适量。
- **豆瓣酱**：腌制肉丝时用少许剁碎同抓（增香）。
- **植物油**：适量。

### 步骤

1. **腌制**：肉丝加剁碎豆瓣酱与淀粉、料酒等抓匀；土豆丝洗净淀粉后，清水里**加少许白醋浸泡**片刻，沥干备用（口感更爽脆）。
2. **煸香料**：热锅放油，小火下蒜末、干辣椒、小米辣、泡椒、花椒等煸出香味。
3. **分炒**：肉丝滑熟后盛出；大火用底油快炒沥干水的土豆丝。
4. **混合**：肉丝回锅，可加青椒丝；**沿锅边淋入一勺醋**，再加生抽、蚝油、盐和少许糖，大火快炒几下出锅。

## 三、红烧家常土豆肉丝（酱香味）

色泽红亮，咸香微甜，酱汁适合拌饭。

### 食材

- **土豆**：1～2 个；**猪瘦肉**：约 150 g。
- **小葱**：切葱花；**大蒜**：切末。
- **老抽、生抽、料酒、白糖、水淀粉**：适量。
- **植物油**：适量；**热水**：少量（收汁用）。

### 步骤

1. **腌制**：肉丝用料酒、老抽、水淀粉抓匀。
2. **土豆丝**：洗净后可**略带一点水分**（不必完全沥干），便于煸炒时形成少许蒸汽。
3. **炒肉丝**：热锅凉油，肉丝滑熟后盛出。
4. **上色**：余油爆香蒜末，倒入带少许水分的土豆丝大火翻炒，加老抽、生抽和约半勺糖炒匀上色。
5. **收汁**：倒回肉丝炒匀；若偏干可加少许热水，**中火 1～2 分钟**至薯丝变软入味、汤汁略稠，撒葱花出锅。

## 四、通用技巧

1. **刀工与洗粉**：土豆**片薄丝才匀**；切丝后**冷水冲洗 2～3 遍**去掉表面淀粉，是爽脆、少粘锅的关键。暂时不用时**泡在水里**防氧化发黑。
2. **肉嫩**：腌肉除淀粉、料酒、生抽外，**最后加一勺油**拌匀锁住水分；炒时用**热锅凉油**，约四五成热滑散，先定型再拨散，减少粘锅。
3. **火候与醋**：全程尽量**大火快炒**，时间短薯丝更脆。适量醋既开胃，也有助于薯丝口感；酸辣版**锅边醋**更能激香。
4. **调色与鲜**：生抽与老抽不宜一次过多同用，避免发黑。出锅前可选加**蚝油**提鲜。

## 五、上桌建议

汤汁略浓时可**盖饭**做盖浇；也可卷入薄饼或夹馒头做快手一餐。
