# 木耳菜家常做法总览

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`时令菜`、`食材/植物/蔬菜/叶菜/木耳菜`

木耳菜（潺菜、紫角叶）可凉拌、快炒、做汤或上汤。**本篇为选购预处理、黏液控制与分项导航**；具体计量与步骤以各独立菜谱为准。

## 二、挑选与清洗

- **挑选**：叶色翠绿、梗部不过分木质化；萎蔫、黏液异常增多者慎用。
- **盐水浸泡**：清水加一小勺盐，浸 **15～20 分钟**，有助去杂，注意叶背；再流水冲净。
- **淘米水 / 面粉水**：浸泡有助于溶解表面污物，再洗净。

## 三、黏液与火候（跨菜谱）

- **急火快炒**：炒制宜全程大火、时间短。
- **焯水凉拌**：焯烫 **20～30 秒**级短时，过凉；久焯易黏液多、口感糊。
- **热炒少加水**：洗净沥干后残留水分往往足够，不必额外加水焖煮。
- **热炒忌重酱油**：易掩盖清香、加重黏液；凉拌、白灼等**少量生抽**通常可接受。
- **出锅时机**：叶片一变色即离火，余温会继续熟化。

## 四、搭配与禁忌

- **搭配**：大蒜最常用；亦可配菌类、肉丝、豆腐等。
- **禁忌**：性偏滑润，**脾胃虚寒者**不宜多食。民间有说与**甲鱼**同食易不适，敏感体质宜留意。

## 五、今晚做哪道？

- **要最清爽**：凉拌木耳菜。  
- **要最快手炒菜**：清炒木耳菜。  
- **要一锅汤**：木耳菜蛋汤。  
- **要鲜醇宴客感**：上汤木耳菜。
