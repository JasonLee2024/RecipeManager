# 上海青家常与经典做法

推荐分类：`炒菜`  
推荐标签：`家常菜`、`时令菜`、`经典菜`、`食材/植物/蔬菜/叶菜/上海青`

上海青烹饪灵活，从几分钟的**清炒、白灼**到浇汁、凉拌、入饭皆可。本文汇总**选购与通用技巧**，具体步骤见各独立菜谱。

## 一、挑选与预处理

- **看色形**：叶**翠绿有光泽**、基部**洁白**；叶**挺括外展**，株型**短壮**者往往更嫩。
- **手感**：握之**饱满有水分**，避免叶已**发蔫**。
- **洗净沥干**：快炒前尽量甩干，减少爆油与出水；大棵宜**梗叶分切**。

## 二、通用技巧

- **焯水保绿**：沸水中加**少许盐与几滴油**，短时焯烫，捞出沥干。
- **控制火时**：炒与灼都以**快**为主，久煮易黄烂、失脆。
- **梗叶分时**：快炒时**先梗后叶**，成熟度一致。
- **提鲜搭配**：可加海米、虾仁、干贝等；素炒可微量**糖**提鲜。
