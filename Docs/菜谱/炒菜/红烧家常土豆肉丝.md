# 红烧家常土豆肉丝

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`场景/工作日`、`口味/咸鲜`、`食材/动物/肉类/猪`、`食材/植物/蔬菜/根茎/土豆`

色泽红亮，咸香微甜，汤汁适合拌饭。刀工、洗粉与肉嫩技巧见：`Docs/菜谱/炒菜/专题/专题_土豆肉丝三做法.md`。

家常酱香做法各地均有，**地域归属不唯一**，不单列菜系标签。

## 食材

- **土豆**：1～2 个，切丝。
- **猪瘦肉**：约 150 g，切丝。
- **小葱**：切葱花。
- **大蒜**：切末。
- **老抽、生抽、料酒、白糖、水淀粉**：适量。
- **植物油**：适量。
- **热水**：少量（收汁用）。

## 做法

1. **腌制**：肉丝用料酒、老抽、水淀粉抓匀。
2. **土豆丝**：洗净后可**略带一点水分**（不必完全沥干），便于煸炒时形成少许蒸汽。
3. **炒肉丝**：热锅凉油，肉丝滑熟后盛出。
4. **上色**：余油爆香蒜末，倒入带少许水分的土豆丝大火翻炒，加老抽、生抽和约半勺糖炒匀上色。
5. **收汁**：倒回肉丝炒匀；若偏干可加少许热水，**中火 1～2 分钟**至薯丝变软入味、汤汁略稠，撒葱花出锅。

## 小贴士

- 老抽用量适中，避免发黑；糖量可按口味微调。
- 收汁阶段留意翻动，防止底部糊锅。
