# 红烧鲈鱼

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`下饭菜`、`场景/工作日`、`食材/动物/海鲜/鲈鱼`、`口味/咸鲜`

鲈鱼少刺、肉嫩，**红烧**前宜先煎定型。下面用一篇问答把「拍粉」说透；实操步骤仍见 **「做法」** 小节。

## 问答详解：鱼身「拍粉」用干粉还是湿粉？

鱼处理干净后，两面拍一层薄面粉或淀粉——有人会问：**是干粉还是湿粉？**问得很细致，这个细节确实会影响成品的卖相和口感。

**答案是：用干粉**，不是湿粉（面糊）。

### 具体操作（干粉）

把**干淀粉**（玉米淀粉、土豆淀粉）或**干面粉**直接撒在鱼身上，或者放在盘子里，让鱼两面滚一下，再轻轻抖掉多余的粉，只留下**薄薄一层**。

### 为什么用干粉，而不是调成湿面糊？

1. **目的不同**：这一步的主要目的是**吸干鱼皮表面的水分**，让鱼下锅时，鱼皮能迅速变脆、定型，不容易粘锅破皮。同时，煎出来的鱼皮是焦香酥脆的。
2. **湿粉（面糊）的问题**：如果把面粉或淀粉和水调成稀糊状再去裹鱼，那就叫做「挂糊」，通常是用来做**炸鱼**（比如糖醋鱼、松鼠鱼）。这种做法糊层比较厚，烧制后容易变得软塌、脱浆，**不适合做红烧**。

### 正确操作步骤（干拍粉）

1. 鱼处理好后，用厨房纸**彻底擦干**鱼身内外的水分（这是很关键的一步）。
2. 将干淀粉或干面粉倒在一个大盘子里，薄薄铺一层。
3. 把鱼放在粉上，两面都轻轻按压一下，让鱼身沾满粉。
4. 提起鱼，轻轻**抖掉多余的粉**，只留下似有似无的一层白霜。
5. **静置 1～2 分钟**，让粉回潮，这样煎的时候粉不容易脱落。

### 选材与可选做法

- **淀粉比面粉好**：建议优先用**玉米淀粉**或**土豆淀粉**。淀粉颗粒小，煎出来的鱼皮更脆、更亮，红烧后不容易变得黏糊糊的。普通面粉也可以，但脆度稍差，容易回软。
- **如果鱼皮没破**：如果你对自己的煎鱼技术很有信心，而且鱼非常干爽，**不拍粉直接煎**也是可以的。但对于新手来说，拍一层薄薄的**干淀粉**是防粘锅、保鱼皮的「法宝」。

**总结**：**干拍粉** → 油热下锅 → 煎到两面金黄 → 再红烧。按照这个方法，鲈鱼皮更容易完整又好吃。

## 食材

- **鲈鱼**：1 条（约 450～650 g），去鳞去内脏洗净。
- **干淀粉**：玉米淀粉或土豆淀粉约 2～3 汤匙（平盘薄铺用）；也可用干面粉，脆度略逊、易回软。
- **生姜**：1 小块，切片。
- **大葱**：半根至 1 根，切段。
- **大蒜**：3～4 瓣，拍松或切粒。
- **料酒**：2 汤匙。
- **生抽**：2 汤匙；**老抽**：1/2～1 茶匙（上色）。
- **白糖**：1～1.5 茶匙（提鲜、和咸）。
- **香醋**：1/2 茶匙（起锅前提香，可选）。
- **食盐**：少许（腌鱼或最后补味）。
- **植物油**：煎鱼用量略宽。
- **清水或高汤**：约 200～300 ml（烧汁用）。

## 做法

### 干拍粉与煎鱼

（要点与上文 **「正确操作步骤（干拍粉）」** 一致，以下为紧凑核对清单。）

1. **擦干**：鱼身内外用厨房纸**彻底吸干**，改一字花刀或浅斜刀（可选），表皮干爽是脆皮前提。
2. **干拍粉**：平盘铺一层干淀粉（或干面粉）。鱼身两面在粉上**轻按**沾粉，提起后**抖掉多余粉**，只留极薄一层似白霜。
3. **回潮**：拍粉后**静置 1～2 分钟**，让粉略粘附，煎时不易脱落。
4. **煎制**：锅烧热倒油，油温中高时下鱼，**先定型再轻晃锅**，中火煎至两面金黄盛出（勿频繁翻面，防破皮）。

### 红烧

5. 留底油，爆香姜片、葱段、蒜，烹料酒，加生抽、老抽、白糖与清水烧开。
6. 放入煎好的鲈鱼，中火浇淋或半浸烧 **8～12 分钟**（视鱼大小），翻面一次或不断浇汁助上色入味。
7. 汤汁收浓时，沿锅边淋少许香醋（可选），将鱼装盘；余汁可勾薄芡（可选）淋在鱼身。

## 小贴士

- **干粉 / 湿粉**：务必**干粉薄沾**；勿调成湿面糊当红烧前的裹粉（详见上文 **「问答详解」**）。
- **淀粉优于面粉**：优先玉米淀粉或土豆淀粉，皮更脆、更亮；面粉易回软。
- **可省略拍粉**：鱼身极干、锅温与油量到位且经验丰富时可直接煎；新手建议薄干淀粉护皮。
