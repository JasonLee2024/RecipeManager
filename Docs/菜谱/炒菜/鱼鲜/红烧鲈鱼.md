# 红烧鲈鱼

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`下饭菜`、`场景/工作日`、`食材/动物/海鲜/鲈鱼`、`口味/咸鲜`

鲈鱼少刺、肉嫩，**红烧**前宜先煎定型。煎前上粉须用**干粉**（干淀粉或干面粉）在鱼身拍**薄粉**，目的是**吸干表皮水分**，下锅后皮脆定型、不易粘锅破皮；**不要**调成湿面糊挂糊（那是炸鱼思路，糊厚易软塌，不适合红烧）。

## 食材

- **鲈鱼**：1 条（约 450～650 g），去鳞去内脏洗净。
- **干淀粉**：玉米淀粉或土豆淀粉约 2～3 汤匙（平盘薄铺用）；也可用干面粉，脆度略逊、易回软。
- **生姜**：1 小块，切片。
- **大葱**：半根至 1 根，切段。
- **大蒜**：3～4 瓣，拍松或切粒。
- **料酒**：2 汤匙。
- **生抽**：2 汤匙；**老抽**：1/2～1 茶匙（上色）。
- **白糖**：1～1.5 茶匙（提鲜、和咸）。
- **香醋**：1/2 茶匙（起锅前提香，可选）。
- **食盐**：少许（腌鱼或最后补味）。
- **植物油**：煎鱼用量略宽。
- **清水或高汤**：约 200～300 ml（烧汁用）。

## 做法

### 干拍粉与煎鱼

1. **擦干**：鱼身内外用厨房纸**彻底吸干**，改一字花刀或浅斜刀（可选），表皮干爽是脆皮前提。
2. **干拍粉**：平盘铺一层干淀粉（或干面粉）。鱼身两面在粉上**轻按**沾粉，提起后**抖掉多余粉**，只留极薄一层似白霜。
3. **回潮**：拍粉后**静置 1～2 分钟**，让粉略粘附，煎时不易脱落。
4. **煎制**：锅烧热倒油，油温中高时下鱼，**先定型再轻晃锅**，中火煎至两面金黄盛出（勿频繁翻面，防破皮）。

### 红烧

5. 留底油，爆香姜片、葱段、蒜，烹料酒，加生抽、老抽、白糖与清水烧开。
6. 放入煎好的鲈鱼，中火浇淋或半浸烧 **8～12 分钟**（视鱼大小），翻面一次或不断浇汁助上色入味。
7. 汤汁收浓时，沿锅边淋少许香醋（可选），将鱼装盘；余汁可勾薄芡（可选）淋在鱼身。

## 小贴士

- **淀粉优于面粉**：优先玉米淀粉或土豆淀粉，皮更脆、更亮，红烧后不易发黏。
- **技术自信时可省略拍粉**：鱼身极干、锅温与油量到位，也可直接煎；新手建议**薄干淀粉**防粘保皮。
- **流程记忆**：干拍粉 → 油热下锅 → 煎两面金黄 → 再红烧。
