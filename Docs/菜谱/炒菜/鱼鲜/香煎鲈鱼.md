# 香煎鲈鱼

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`食材/动物/海鲜/鲈鱼`、`口味/咸鲜`、`粤菜`

取鱼柳或半片鱼身**中火煎制**，鱼皮酥脆、鱼肉细嫩；在西餐与粤菜海鲜料理中都常见煎鲈鱼做法。

## 食材

- **鲈鱼**：1 条取两片鱼柳，或半片带皮鱼身（约 250～400 g 鱼肉）。
- **食盐、黑胡椒**：适量（腌鱼）。
- **植物油**：平底锅铺满薄层。
- **柠檬**：1/4～1/2 个（挤汁佐餐）。
- **配菜（可选）**：芦笋、小番茄等。

## 做法

1. 鱼肉用厨房纸**彻底吸干**表面水分；两面抹少许盐与黑胡椒，腌制 **10 分钟**。
2. 平底锅中小火预热，倒油；**鱼皮朝下**入锅，用铲轻压使皮贴锅，煎 **3～4 分钟**至金黄酥脆。
3. 翻面再煎 **2～3 分钟**至鱼肉不透明、中心仍保持多汁。（厚度大者可转小火稍延长。）
4. 盛出搭配配菜，上桌前挤少许柠檬汁。

## 小贴士

- 鱼皮脆的关键：**干爽** + **中等油温** + **皮面先下锅定型**，勿过早翻动。
- 整鱼煎制可先沿脊骨剖开摊平（蝴蝶切），更易煎透。
- 海鲈鱼减盐。
