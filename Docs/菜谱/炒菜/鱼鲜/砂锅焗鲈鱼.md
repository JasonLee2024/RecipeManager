# 砂锅焗鲈鱼

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`厨具/砂锅`、`食材/动物/海鲜/鲈鱼`、`口味/咸鲜`、`粤菜`

做法类似广东**啫啫煲**：砂锅蓄热、蒜姜爆香，鱼肉焗熟吸饱酱香；锅盖淋米酒增香是常见一招。

## 食材

- **鲈鱼**：1 条切块（或大片），约 450～650 g。
- **食盐**：少许。
- **蚝油**：1 汤匙。
- **生抽**：1 汤匙。
- **海鲜酱**（或黄豆酱）：1～2 茶匙。
- **生粉（淀粉）**：1～2 茶匙。
- **生姜**：数片或小块。
- **大蒜**：1～2 头蒜瓣（多才香）。
- **洋葱**：半个至 1 个，切块。
- **米酒或黄酒**：约 2～3 汤匙（沿锅盖淋入）。
- **植物油**：适量。
- **葱花**：少许。

## 做法

1. 鱼块用盐、蚝油、生抽、海鲜酱、生粉与姜片抓匀，腌制 **20 分钟**。
2. **砂锅**中火烧热，倒油，爆香大量蒜瓣、姜块与洋葱块。
3. 铺上腌好的鱼块（腌汁可一并倒入），加盖。
4. 沿锅盖边缘淋一圈**米酒**，中火焗 **8～10 分钟**，鱼肉熟透即可。
5. 开盖撒葱花，趁热上桌。

## 小贴士

- 砂锅需事先检查无裂纹；焗制全程保持中火，避免糊底。
- 鱼块下锅前再用厨房纸**轻吸表面**，减少溅油与水汽过多。
- 酱料咸度已够时慎补盐；海鲈鱼宜减蚝油或生抽。
