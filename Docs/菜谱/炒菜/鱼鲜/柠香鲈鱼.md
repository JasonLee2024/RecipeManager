# 柠香鲈鱼

推荐分类：`炒菜`  
推荐标签：`家常菜`、`口味/清淡`、`场景/夏日`、`食材/动物/海鲜/鲈鱼`、`口味/酸辣`

在清蒸鲈鱼的基础上，用鱼露、青柠与辣椒调成**酸辣汁**，清爽开胃，适合夏季或想换口味时尝试。（风味接近东南亚家常酸辣蒸鱼，地域标签以文档可核对依据为准，此处不强行归入国内八大菜系。）

## 食材

- **鲈鱼**：1 条（约 450～650 g），处理干净。
- **生姜、大葱**：适量（蒸鱼用，同清蒸鲈鱼）。
- **鱼露**：1.5～2 汤匙。
- **青柠**：2～3 个（取汁，另切几片装饰）。
- **大蒜**：2～3 瓣，切末。
- **小米辣**：1～2 根，切圈（按耐辣调整）。
- **白糖**：1～1.5 茶匙（平衡咸酸）。
- **香菜**：少许（可选）。
- **植物油**：少许（若需浇热油可省略或减量）。

## 做法

1. 鲈鱼按**清蒸鲈鱼**方法蒸熟：水开后大火蒸 8～10 分钟，关火虚蒸约 2 分钟。
2. 蒸鱼期间调制酱汁：鱼露、青柠汁、蒜末、小米辣、白糖加少许温开水调匀，尝味补甜或补酸。
3. 取出鱼盘，**倒掉蒸汁**，淋上调好的酸辣汁。
4. 铺青柠片与香菜，即可食用。（喜香者可轻淋一点点热油。）

## 小贴士

- 鱼露咸度高，注意尝味后再补盐。
- **吸干鱼身水分**再蒸，腥气更低、肉质更利落。
- 海鲈鱼偏咸时减少鱼露用量。
