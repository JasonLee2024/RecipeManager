# 花蛤炒葛根粉条

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`快手菜`、`食材/加工与其他/米面主食/葛根粉条`、`口味/咸鲜`

花蛤提鲜，配虾仁、鸡蛋与葛根粉条同炒，**鲜甜饱满**；粉条宜先煮后炒，吸汁不烂。

## 食材

- **葛根粉条**：干约 80～100 g。
- **花蛤**：300～400 g，吐沙洗净。
- **鲜虾仁**（可选）：数只。
- **鸡蛋**：1～2 个，打散。
- **大葱或小葱**：适量。
- **生姜**：2 片，切丝。
- **大蒜**：2 瓣，切末。
- **料酒**：1 汤匙。
- **生抽**：1～1.5 汤匙。
- **蚝油**：1 汤匙。
- **食盐、白糖**：少许。
- **植物油**：适量。

## 做法

1. 粉条泡软，煮熟沥干备用。
2. 花蛤沸水加料酒焯至开口即捞出，留少许汤汁过滤备用；未开口的丢弃。
3. 鸡蛋炒散盛出；锅中爆香姜蒜，下虾仁炒至变色。
4. 倒入花蛤与粉条，加生抽、蚝油、糖与少量焯蛤清汤，大火翻匀；回鸡蛋、撒葱花，按口味补盐出锅。

## 小贴士

- 吐沙可用淡盐水静养 1～2 小时。
- 蛤汤带咸鲜，加盐前先尝味。
