# 清蒸鲈鱼

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`口味/清淡`、`场景/工作日`、`食材/动物/海鲜/鲈鱼`、`口味/咸鲜`、`粤菜`

鲈鱼细嫩少刺，**清蒸**最能吃到本味。豉油、葱丝与热油激发香气——此类做法在**粤菜**馆与家常厨房都很常见。

## 食材

- **鲈鱼**：1 条（约 450～650 g），去鳞去鳃去内脏洗净。
- **生姜**：1 小块，切薄片。
- **大葱**：适量，部分切段塞鱼腹，部分切细丝铺面。
- **红椒**（可选）：少许切丝，配色。
- **蒸鱼豉油**：3～4 汤匙（可按口味增减）。
- **植物油**：1～2 汤匙（浇热油用）。
- **料酒**（可选）：1 汤匙（抹鱼身或垫盘少许）。

## 做法

1. 鱼身两面斜划几刀至鱼骨，方便受热均匀；鱼腹塞入姜片与葱段。
2. 盘底可垫两根筷子或葱段架空鱼身，使蒸汽流通（可选）。
3. 蒸锅**水烧开**后再放鱼盘，**大火**蒸 **8～10 分钟**（视鱼大小增减），关火后虚蒸约 **2 分钟**。
4. 取出后**倒掉盘中汤汁**（减少腥气），拣去蒸蔫的旧葱姜。
5. 铺上新鲜葱丝、红椒丝，淋**蒸鱼豉油**；将油烧至微微冒烟，**浇在葱丝上**激香即成。

## 小贴士

- 鱼身内外用**厨房纸吸干水分**，蒸制与调味更清爽。
- 若使用**海鲈鱼**，自体含盐度较高，豉油可酌减。
- 蒸制时间以鱼眼略凸、骨肉易离刺为度，过久肉质易柴。
