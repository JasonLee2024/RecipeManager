# 土豆毛豆葛根粉条一锅烧（干锅 / 大乱炖）

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`经典菜`、`一锅出`、`食材/加工与其他/米面主食/葛根粉条`、`食材/植物/蔬菜/根茎/土豆`、`食材/植物/豆类/毛豆`、`食材/植物/蔬菜/茄果/青椒`、`食材/植物/蔬菜/根茎/洋葱`、`口味/咸鲜`

将土豆、毛豆、葛根粉条与洋葱、青椒同锅，先煸后炖再收汁，省事且味型统一。偏家常一锅出思路，**地域归属不唯一**。喜辣可加干辣椒或郫县豆瓣酱。

## 食材

- **五花肉**：适量，切片（煸油用，也可用其他油脂代替）。
- **洋葱**：适量，切块。
- **土豆**：适量，切块。
- **手剥毛豆**：适量。
- **葛根粉条**：干品适量，温水泡软沥干。
- **青圆椒**：适量，切块。
- **清水或高汤**：适量。
- **生抽、老抽、蚝油**：适量；**盐、白糖**：适量。
- **可选**：干辣椒；郫县豆瓣酱；薄水淀粉（出锅前勾薄芡）。

## 做法

1. 热锅下五花肉煸出油，下洋葱块炒香。
2. 加入土豆块与毛豆翻炒，加水与调料烧开，**中小火**炖至土豆近熟。
3. 加入泡软的粉条与青椒块，**大火**收汁；需要更挂汁时可勾薄芡。
4. 炒匀出锅。

## 小贴士

- 处理顺序建议：先泡粉条，再切土豆、洋葱；青椒、洋葱若希望更脆，可在收汁阶段再下青椒，缩短加热时间。
- 葛根粉条上色可略多加老抽；辣味以干辣椒或豆瓣酱调节。
