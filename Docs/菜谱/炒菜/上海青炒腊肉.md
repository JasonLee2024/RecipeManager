# 上海青炒腊肉

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`经典菜`、`食材/植物/蔬菜/叶菜/上海青`、`食材/加工与其他/加工肉制品/腊肉`、`口味/咸鲜`

先将**腊肉**煸出油，再借油脂香炒上海青，咸香下饭。腊肉自带盐分，**盐与生抽宜少放**。

## 食材

- **上海青**：400～500 g，梗叶分切。
- **腊肉**：80～120 g，切薄片（或肥瘦相间的五花肉片替代）。
- **大蒜**：2～3 瓣，切片。
- **干辣椒**：2～3 个（切段，可选）。
- **生抽**：约 1 茶匙（可选，补色提鲜）。
- **盐**：少许或省略。
- **食用油**：少量（腊肉出油多则少放油）。

## 做法

1. 腊肉片入锅，**中小火煸炒出油**、边缘略卷曲透明。
2. 下蒜片、干辣椒段煸香。
3. 转大火，先下**菜梗**翻炒，再下**菜叶**，沿锅边可淋少许生抽。
4. 炒匀至菜叶塌软仍绿即可出锅；口淡可不再加盐。

## 小贴士

- 腊肉偏硬可先蒸 10 分钟再切炒，口感更匀。
- 油脂过多可滗出一部分再炒菜。
