# 清炒木耳菜（蒜蓉 / 酒香）

推荐分类：`炒菜`  
推荐标签：`快手菜`、`家常菜`、`经典菜`、`场景/工作日`、`食材/植物/蔬菜/叶菜/木耳菜`、`口味/咸鲜`

大火快炒突出木耳菜清香与滑嫩；蒜分两次下，香气更有层次。**酒香版**在清炒基础上加少量白酒，风味更立体。均为各地家庭常见做法，**地域归属不唯一**。

## 食材

- **木耳菜**：适量，掐去老梗，洗净沥干。
- **大蒜**：切末（清炒版分两次下锅）。
- **食盐**：适量。
- **鸡精**：少许（可选）。
- **植物油**：适量。
- **白酒**：约一瓶盖（仅酒香版）。

## 做法

### 蒜蓉清炒

1. 锅烧热倒油，油温七八成热（微微冒烟），转大火下一半蒜末爆香。
2. **立即**下木耳菜快速翻炒至叶软变色。
3. 加盐及少许鸡精调味。
4. 下另一半生蒜末，快速翻炒均匀即可出锅。

### 酒香版

按蒜蓉版炒至木耳菜变软时，沿锅边烹入一瓶盖**白酒**，中大火再炒约 **2 分钟**至完全变软即可。

## 小贴士

- 全程大火快炒、尽量不加多余的水，可减少黏液、保持清脆。
- 热炒阶段忌重酱油（易黏液、压清香）；详见专题总览。
