# 瓠瓜炒蚕豆

推荐分类：`炒菜`  
推荐标签：`家常菜`、`时令`

蚕豆绵软配瓠瓜清甜，清淡但很下饭。蚕豆熟得慢，适合“先炒后焖”。

## 食材

- 瓠瓜 约 300-400 g（去皮切滚刀块/片）
- 蚕豆仁 约 200-300 g（剥好洗净）
- 盐 适量
- 鸡精 少许（可选）
- 食用油 适量

## 做法

1. 瓠瓜去皮切块/片；蚕豆仁洗净。
2. 热锅下油，先下瓠瓜翻炒 1-2 分钟。
3. 加入蚕豆仁同炒 1 分钟，沿锅边加少量热水，盖盖小火焖 5-8 分钟至蚕豆熟软。
4. 开盖大火收一下水汽，加盐（和可选鸡精）调味出锅。

## 小贴士

- 蚕豆若较老可先焯水 1 分钟，焖煮时间更好掌控。
- 瓠瓜清淡，少量白胡椒或葱油也很适合。
