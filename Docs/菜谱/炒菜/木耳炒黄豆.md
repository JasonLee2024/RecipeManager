# 木耳炒黄豆
和清炒相比，把木耳、鸡蛋和**泡发黄豆**这三样炒在一起，黄豆的嚼劲和豆香会让菜的风味更丰富、口感更有层次。

不过，黄豆本身质地偏硬，想炒得好吃，最核心的一步就是——**一定要先把黄豆完全煮熟**。

### 🔪 处理环节

| 食材 | 处理要点 | 处理细节与关键技巧 |
| :--- | :--- | :--- |
| **泡发黄豆** | **必须完全煮熟** | 需提前**浸泡4小时以上**至完全胀发。再冷水下锅，水开后转中小火煮**15-20分钟**，煮到黄豆吃起来**又粉又软**，然后捞出沥干。 |
| **干木耳** | **提前泡发并焯水** | 用**冷水**泡发**2-3小时**，洗净后撕成小朵。**务必用沸水焯烫1-2分钟**，这能缩短炒制时间、让口感更脆爽，也避免下锅时“炸油”。 |
| **鸡蛋** | **提前炒熟盛出** | 打散时加少许**盐和白醋**，盐能提前入味，白醋则能有效去腥增香。下锅滑炒至定型后，盛出备用。 |

### 🍳 烹饪环节

1.  **爆香锅底**：锅中倒油，放入葱、姜、蒜末（喜欢吃辣的可以加点小米辣），用中小火煸炒出香味。

2.  **下主料翻炒**：放入处理好的**木耳**和**煮熟的黄豆**，转**大火**快速翻炒约30秒，让食材充分吸收底油和香气。

3.  **调味并合炒**：
    *   **调味**：沿锅边淋入**生抽1-2勺**和**蚝油1勺**，快速翻炒均匀，激发出酱香。
    *   **合炒**：最后倒入提前炒好的**鸡蛋**，根据口味补加少许**盐**和**白糖**（提鲜），大火快炒让所有食材裹满酱汁。

4.  **出锅装盘**：撒上少许葱花，即可出锅装盘。

### ⚠️ 关键技巧与注意事项

*   **黄豆必须煮熟**：生黄豆含皂素，**一定要彻底煮熟**才能安全食用。提前煮熟不仅能确保安全，也大大缩短了最后炒制的时间，让操作更从容。
*   **食材沥干是防溅油的关键**：木耳和黄豆下锅前，务必**充分沥干水分**。任何多余的水分接触热油都会引起剧烈迸溅，甚至烫伤。
*   **善用大火快炒**：这道菜的所有食材都已预处理至可食用状态，最后炒制的核心目的是**融合味道**。所以一定要用**大火**快速翻炒，整个炒制过程应控制在**1-2分钟**内，避免将黄豆或木耳炒得失去口感。

---

这道菜很下饭，也很适合带便当。如果喜欢更浓郁的酱香，也可以把盐换成一小勺黄豆酱，能让风味更有层次。

这三种食材在预处理阶段都有各自的讲究，如果你在处理黄豆或木耳时遇到具体问题，比如怎么快速泡发木耳，随时可以再来问我～
