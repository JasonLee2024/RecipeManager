# 白灼上海青

推荐分类：`炒菜`  
推荐标签：`快手菜`、`家常菜`、`经典菜`、`粤菜`、`食材/植物/蔬菜/叶菜/上海青`、`口味/咸鲜`

**白灼**是**粤菜**中突出原味的经典技法：青菜焯熟，配豉油与热油激香蒜末，清爽利落。

## 食材

- **上海青**：400～500 g。
- **大蒜**：3～4 瓣，切末。
- **蒸鱼豉油**（或生抽）：1.5～2 汤匙。
- **盐**：足量（焯水用，略多于日常煮汤）。
- **食用油**：1.5～2 汤匙（泼油用）。

## 做法

1. **焯水**：水大开，加**足量盐**与几滴油，下上海青，**灼烫约 1.5～2 分钟**至熟仍挺，捞出沥干，**整齐码盘**。
2. **组合**：表面撒蒜末，淋上蒸鱼豉油（或生抽）。
3. **泼油**：另取小锅将油烧至**明显冒烟**，趁热浇在蒜末上激香即成。

## 小贴士

- 盐与油帮助保绿；捞出后**轻压沥水**，避免稀释豉油咸度。
- 泼油时注意安全，可用长柄勺淋油。
