# 毛豆土豆烧粉条

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`经典菜`、`场景/工作日`、`食材/加工与其他/米面主食/葛根粉条`、`食材/植物/蔬菜/根茎/土豆`、`食材/植物/豆类/毛豆`、`口味/咸鲜`

土豆、手剥毛豆与葛根粉条同烧，粉条吸饱汤汁，软糯鲜香；毛豆与土豆提供淀粉与蛋白搭配，色彩也清爽。各地家庭常见做法，**地域归属不唯一**。可与 `Docs/菜谱/炒菜/青圆椒炒洋葱.md` 一烧一炒搭配。

## 食材

- **土豆**：适量，去皮切成约 **1.5 厘米见方**小丁。
- **手剥毛豆**：适量。
- **葛根粉条**：干品适量，**温水泡软**至无硬芯，捞出沥干（食用前可剪短）。
- **清水或高汤**：没过食材。
- **生抽、老抽、蚝油**：调味（老抽助上色，葛根粉条较“吃”酱油）。
- **盐、白糖**：适量。
- **植物油**：适量。
- **可选**：五花肉几片；干辣椒、八角少许增香。

## 做法

1. 锅中倒油，下土豆丁**煎至表面微焦**。
2. 加入毛豆翻炒；可选：下五花肉煸出油，或加干辣椒、八角煸香。
3. 倒入没过食材的清水或高汤，放入泡软的粉条。
4. 加生抽、老抽、蚝油、盐和糖调味，**中火**烧 **5～8 分钟**，至土豆软烂、粉条透明、汤汁浓稠即可。

## 小贴士

- 粉条宜提前泡好；土豆切小丁更易炖软入味。
- 手剥毛豆较嫩时可不焯水；若担心豆腥味，可开水焯烫约 **1 分钟**再下锅。
- 喜辣可加干辣椒或少量郫县豆瓣酱（见一锅烧变体）。
