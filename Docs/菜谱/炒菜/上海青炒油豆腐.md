# 上海青炒油豆腐

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`快手菜`、`食材/植物/蔬菜/叶菜/上海青`、`口味/咸鲜`

油豆腐对半切开，与上海青同炒，吸饱蚝油与生抽汤汁，**一软一脆**，层次丰富。

## 食材

- **上海青**：350～450 g，梗叶分切更佳。
- **油豆腐**：约 150～200 g，对半切开。
- **大蒜**：2～3 瓣，切片或末。
- **生抽**：约 1 汤匙。
- **蚝油**：约 1 汤匙。
- **白糖**：少许（提鲜）。
- **盐**：适量。
- **食用油**：适量。
- **清水**：2～3 汤匙（给油豆腐吸汁）。

## 做法

1. 热锅倒油，爆香蒜片或蒜末。
2. 先下**菜梗与油豆腐**，中火翻炒片刻，加少量清水，盖盖**焖约 1 分钟**让油豆腐回软吸味。
3. 下**菜叶**，转大火，加生抽、蚝油、糖翻匀。
4. 按口味补盐，汤汁收到满意程度即可出锅。

## 小贴士

- 油豆腐偏干时多给一勺水，**分次少加**防糊底。
- 喜辣可加干辣椒段与蒜同爆。
