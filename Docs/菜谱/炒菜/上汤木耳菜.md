# 上汤木耳菜

推荐分类：`炒菜`  
推荐标签：`粤菜`、`快手菜`、`家常菜`、`经典菜`、`食材/植物/蔬菜/叶菜/木耳菜`、`口味/咸鲜`

经典**粤菜**做法：皮蛋、咸蛋与高汤煮成浓白上汤，浇在焯水的木耳菜上，鲜醇清甜、层次丰富。地域依据：菜式归属粤菜馆常见「上汤时蔬」体系。

## 食材

- **木耳菜**：适量，洗净。
- **皮蛋、咸鸭蛋**：切丁。
- **大蒜**：拍碎。
- **姜**：切丝。
- **高汤或清汤**：适量。
- **植物油**：适量。

## 做法

1. 皮蛋、咸鸭蛋切丁；蒜拍碎；姜切丝。
2. 木耳菜快速焯水约 **10 秒**，捞出控干，铺入碗中（去涩、保翠绿）。
3. 锅中放油，下蒜瓣炸至金黄，再下姜丝与皮蛋丁炒香。
4. 倒入高汤煮沸，稍熬至汤色浓白，淋在木耳菜上即可。

## 小贴士

- 高汤可用鸡汤、骨汤或合格清汤底料；咸蛋自带咸味，加盐需保守。
