# 葛根粉条煲

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`经典菜`、`食材/加工与其他/米面主食/葛根粉条`、`口味/咸鲜`

鸡肉、鱼丸、豆腐等与葛根粉条**小火慢炖**，汤汁浓厚；适合秋冬一锅端。

## 食材

- **葛根粉条**：干约 80～100 g。
- **鸡腿肉或鸡块**：300～400 g，切块。
- **鱼丸或鱼豆腐**：适量（可选）。
- **老豆腐或冻豆腐**：200 g 左右，切块。
- **香菇**：3～4 朵，切块（可选）。
- **生姜**：数片；**大蒜**：3 瓣。
- **生抽**：2 汤匙；**蚝油**：1 汤匙（可选）。
- **料酒**：1 汤匙。
- **食盐、白糖**：适量。
- **清水或高汤**：约没过食材。
- **植物油**：适量。

## 做法

1. 粉条温水泡软；鸡肉冷水下锅焯去血沫，捞出洗净（可选步骤）。
2. 砂锅或厚底锅烧热油，煸香姜蒜，下鸡块炒至表面微黄，淋料酒。
3. 加清水或高汤烧开，下豆腐、香菇，中小火炖 **15～20 分钟**。
4. 下鱼丸与泡软的粉条，加生抽、蚝油、糖，再炖 **8～12 分钟**至粉条入味；补盐，汤汁收到满意程度即可。

## 小贴士

- 粉条后下，避免久炖成糊；汤量不足可中途加热水。
- 喜辣可加干辣椒与姜蒜同煸。
