# 五花肉洋葱炒葛根粉丝（配上海青）

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`场景/工作日`、`食材/加工与其他/米面主食/葛根粉条`、`食材/动物/肉类/猪`、`食材/植物/蔬菜/葱姜蒜/洋葱`、`食材/植物/蔬菜/叶菜/上海青`、`食材/植物/蔬菜/葱姜蒜/蒜`、`口味/咸鲜`、`口味/香辣`

只用 **洋葱、上海青、五花肉、葛根粉丝** 四种主料，做成一盘下饭的菜。做法走 **干锅 / 小炒** 路线——五花肉煸出油，洋葱炒软出甜味，上海青保持脆嫩，葛根粉丝吸饱肉汁和酱香。全程不用番茄、土豆、香菇，同样非常下饭。

全国各地家常小炒思路，**地域归属不唯一**，故不单列八大菜系等地域标签。

## 食材（2人份）

- **五花肉** 150g（去皮切薄片）
- **洋葱** 半个（约100g，切丝）
- **上海青** 3-4棵（洗净，梗叶分开切段）
- **葛根粉丝** 1小把（约50g，干品）
- **蒜** 2瓣（切片）
- **干辣椒** 1-2个（可选，增香辣）
- **调料**：食用油（少量，五花肉会出油）、生抽、老抽、蚝油、糖、白胡椒粉、盐

可选：

- **料酒** 半勺（煸炒五花肉时沿锅边淋入去腥）
- **豆瓣酱** 1勺（与洋葱同炒，更辣更酱；需减少生抽与盐）
- **香醋** 几滴或**葱花**（出锅前提香）

## 准备步骤

1. **葛根粉丝**：温水泡10-15分钟至软，沥干，剪几刀防缠绕。若要色深根根分明，可沥干后加半勺老抽拌匀，腌约5分钟备用。
2. **五花肉**：切薄片，一般不腌，靠煸炒出香。
3. **洋葱**切丝；**上海青**梗、叶分开切段。
4. **蒜**切片；**干辣椒**切段（若用）。

## 烹饪步骤

### 1. 煸炒五花肉（出油是关键）

- 锅烧热，放少许油润底，下五花肉片，**中火**煸炒至卷曲、表面金黄、油脂大量渗出（约2-3分钟）。
- 油过多可倒出部分，留底油。
- 沿锅边淋半勺料酒去腥（可选），炒香。

### 2. 洋葱、蒜、辣椒

- 下蒜片、干辣椒、洋葱丝，**大火**翻炒约1分钟，至洋葱变软、边缘微焦、出甜味。

### 3. 上海青（先梗后叶）

- 先下**梗**，大火翻炒约30秒至梗半透明。
- 再下**叶**，快速翻炒至变软（约20秒）。

### 4. 下葛根粉丝并调味

- 转**中小火**，将泡软的葛根粉丝铺在菜上。
- 加 **2勺生抽、半勺老抽、1勺蚝油、少许糖与白胡椒粉**；快速拌匀，让粉丝裹匀酱汁。
- 偏干时沿锅边淋 **2-3勺热水**（宜热水，不宜多），粉丝吸汁后更油润Q弹。

### 5. 收汁出锅

- **大火**快炒约30秒，汤汁收浓，粉丝透明、根根分明。
- 尝味补盐（生抽、蚝油已有咸味，常可不加）。
- 关火装盘。

## 成品特点

- **五花肉**：焦香不腻，边缘微脆，油润渗入粉丝。
- **洋葱**：炒软变甜，辛辣感弱，与肉香融合。
- **上海青**：梗脆叶嫩，解腻清鲜。
- **葛根粉丝**：爽滑Q弹，吸饱酱油与肉汁，不易粘坨。

## 让这道菜特别下饭的三个技巧

1. **五花肉煸透**：逼出猪油，肉片呈「灯盏窝」状，香而不腻；油脂被粉丝吸收后特别润。
2. **粉丝泡软后可拌老抽**：色更红亮、更入味，炒完根根分明。
3. **起锅前补汁用热水**：粉丝易干，少量热水助其吸汁变软弹；冷水易使口感发硬。

## 替代与变化

- **无葛根粉丝**：可用红薯粉丝或龙口粉丝；龙口粉丝温水泡约5分钟即可。
- **更辣**：加豆瓣酱与洋葱同炒，注意减生抽与盐。
- **更香**：出锅前淋几滴醋或撒葱花。

## 味道描述

洋葱焦甜与猪油香先飘出来；五花肉油亮微卷，上海青仍带脆绿。粉丝酱色饱满，挑一筷弹滑不断。连菜带粉丝盖在热米饭上，咸鲜里透着洋葱的甜与青菜的脆，油脂浸润米粒——一盘即可轻松下两碗饭。
