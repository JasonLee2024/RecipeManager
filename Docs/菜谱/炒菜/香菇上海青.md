# 香菇上海青

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`经典菜`、`食材/植物/蔬菜/叶菜/上海青`、`食材/植物/蔬菜/菌菇/香菇`、`口味/咸鲜`

上海青焯水垫底，**香菇**以蚝油、生抽、糖烧成芡汁浇上，口感一脆一滑，咸甜适口。此组合在**粤式**小炒与宴客素菜中很常见。

## 食材

- **上海青**：400～500 g。
- **鲜香菇**（或泡发香菇）：120～150 g，切片或切花刀。
- **大蒜**：2～3 瓣，切末。
- **蚝油**：约 1 汤匙。
- **生抽**：约 1 茶匙。
- **白糖**：1/3～1/2 茶匙（提鲜、平衡咸度）。
- **盐**：焯水用少许。
- **食用油**：适量。
- **水淀粉**：少许（勾芡用）。

## 做法

1. **处理**：上海青洗净；香菇切片备用。
2. **焯上海青**：沸水加少许盐与油，下上海青焯熟，捞出沥干装盘。
3. **焯香菇（可选）**：同一锅水再焯香菇数十秒去土腥，沥干。
4. **烧香菇芡**：热锅少油，**爆香蒜末**，下香菇翻炒，加蚝油、生抽、糖与少量水煮开，**淋入水淀粉**勾薄芡至汤汁挂勺。
5. **合体**：将香菇与芡汁浇在上海青上。

## 小贴士

- 芡汁宜**薄而亮**，过厚易腻；糖量宜少，以不吃出明显甜味为佳。
