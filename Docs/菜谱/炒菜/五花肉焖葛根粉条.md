# 五花肉焖葛根粉条

推荐分类：`炒菜`  
推荐标签：`家常菜`、`下饭菜`、`经典菜`、`食材/加工与其他/米面主食/葛根粉条`、`食材/动物/肉类/猪`、`口味/咸鲜`

五花肉煸出油脂，再与葛根粉条焖煮，**肥而不腻、粉条油润**；思路类似扣肉吸汁，操作更家常。

## 食材

- **葛根粉条**：干约 80～100 g。
- **五花肉**：250～300 g，切厚片或麻将块。
- **生姜**：数片；**大蒜**：3 瓣；**大葱**：1 段。
- **生抽**：2 汤匙；**老抽**：1 茶匙。
- **料酒**：1 汤匙；**白糖**：1 茶匙。
- **食盐**：少许。
- **清水**：适量。

## 做法

1. 粉条泡软；五花肉可冷水焯水去沫（可选）。
2. 锅中放少量底油，下五花肉**中小火煸炒出油**、表面微焦黄。
3. 下姜蒜葱炒香，淋料酒，加生抽、老抽、糖与清水没过肉块，大火烧开转小火焖 **25～35 分钟**至肉软。
4. 下泡软的粉条铺在肉上，浸没汤汁，盖盖再焖 **10～15 分钟**，收汁翻匀；按口味补盐出锅。

## 小贴士

- 油脂过多可滗出一部分再下粉条。
- 喜酱色可加少量黄豆酱或豆瓣酱（咸度需相应减少盐）。
