# 酸辣土豆肉丝

推荐分类：`炒菜`  
推荐标签：`家常菜`、`经典菜`、`场景/工作日`、`口味/酸辣`、`食材/动物/肉类/猪`、`食材/植物/蔬菜/根茎/土豆`、`食材/植物/蔬菜/茄果/青椒`

偏重口开胃，**酸、辣、香**为主；锅边醋能更好激香。共用刀工、腌肉与火候要点见：`Docs/菜谱/炒菜/专题/专题_土豆肉丝三做法.md`。

全国各地家常变化较多，**地域归属不唯一**，不单列菜系标签。

## 食材

- **土豆**：1～2 个，切丝。
- **猪瘦肉**：约 150 g，切丝。
- **干辣椒 / 小米辣 / 泡椒**：按嗜辣程度选用。
- **青椒**：可选，切丝。
- **大蒜**：切末；**花椒**：少许（可选）。
- **醋**：白醋或香醋。
- **生抽、蚝油、食盐、白糖、料酒、淀粉**：适量。
- **豆瓣酱**：少许剁碎，腌制肉丝时用（增香）。
- **植物油**：适量。

## 做法

1. **腌制**：肉丝加剁碎豆瓣酱与料酒、淀粉等抓匀；土豆丝洗净淀粉后，于清水**加少许白醋**浸泡片刻再沥干（口感更爽脆）。
2. **煸香料**：热锅放油，小火下蒜末、干辣椒、小米辣、泡椒、花椒等煸出香味。
3. **分炒**：肉丝滑熟后盛出；大火用底油快炒沥干水的土豆丝。
4. **混合**：肉丝回锅，可加青椒丝；**沿锅边淋入一勺醋**，再加生抽、蚝油、盐和少许糖，大火快炒几下出锅。

## 小贴士

- 酸辣层次可依泡椒、小米辣与醋的品种微调；醋建议出锅前沿锅边淋入。
- 土豆丝沥干再下锅，避免油温骤降。
