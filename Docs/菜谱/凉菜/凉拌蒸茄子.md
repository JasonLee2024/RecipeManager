# 凉拌蒸茄子



推荐分类：`凉菜`  

推荐标签：`快手菜`、`家常菜`、`时令菜`



大圆茄子去皮后非常适合蒸熟再凉拌，口感比带皮更软糯、更易入味；整体为家常做法，各地常见。



## 食材



- 大圆茄子 1 个

- 大蒜 适量（切末）

- 生抽、香醋 适量

- 白糖 少许

- 香油、辣椒油 适量（辣椒油可选）

- 小葱或香菜 少许（可选）

- 白醋 少许（可选，防氧化）



## 做法



1. **去皮切块**：茄子去皮，切成粗条或厚片；不要切太细，以免蒸后易碎。

2. **蒸制**：水开后上锅蒸 8～10 分钟（视块大小调整），蒸至筷子能轻松扎透即可。若担心去皮后氧化变色，切好后尽快上锅，或蒸前用极淡白醋水略浸。

3. **控水晾凉**：倒出蒸出的多余汤汁，用筷子轻轻拨散，晾凉（可略挤去水分）。

4. **调味**：加入蒜末、生抽、香醋、少许糖、香油、辣椒油等，撒葱花或香菜，拌匀即可。



## 小贴士



- 蒸好后尽量控干水，否则拌出来汤汁多、味道易偏淡。

- 清爽少油，适合夏季佐餐。
