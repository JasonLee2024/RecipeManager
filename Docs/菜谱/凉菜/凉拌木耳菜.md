# 凉拌木耳菜

推荐分类：`凉菜`  
推荐标签：`快手菜`、`家常菜`、`时令菜`、`场景/夏日`、`食材/植物/蔬菜/叶菜/木耳菜`、`口味/咸鲜`

焯水时间短、过凉后泼油激蒜，能最大限度保留木耳菜（潺菜、紫角叶）的清香与爽脆，适合夏天。**各地家常凉拌思路相近，地域归属不唯一。**

## 食材

- **木耳菜**：适量，洗净。
- **大蒜**：切末。
- **小米辣**：切圈（可选）。
- **生抽、陈醋、蚝油、香油、糖、盐**：调成拌汁，用量按口味。
- **食用油**：少许，烧热泼蒜用。

## 做法

1. **焯水**：水沸下木耳菜，大火焯约 **20～30 秒**，叶软翠绿即捞出；久了易出黏液、口感发黏。
2. **控水**：捞出过凉水，沥干装盘。
3. **泼油**：蒜末、小米辣置于木耳菜上；油烧热至微微冒烟，浇上激香。
4. **拌匀**：淋入生抽、陈醋、蚝油、香油、糖、盐调成的酱汁，拌匀即可。

## 小贴士

- 焯水务必短时；拌食可比热炒略多用少量生抽（见专题「黏液与调味」说明）。
