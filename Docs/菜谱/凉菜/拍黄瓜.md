# 拍黄瓜

推荐分类：`凉菜`  
推荐标签：`快手菜`、`家常菜`、`口味/咸鲜`

旱黄瓜或小黄瓜皆可；拍裂后断面不规则，更易挂汁入味，突出**清脆**与蒜香、酸香。

## 食材

- 旱黄瓜或小黄瓜 2 根（约 400–500 克）
- 大蒜 3–4 瓣（切末）
- 生抽 1.5–2 勺
- 香醋 1–1.5 勺
- 香油 半勺
- 白糖 半茶匙至 1 茶匙（提鲜、柔酸）
- 盐 少许
- 花椒油 少许（可选）
- 干辣椒段 少许（可选，可用热油略炝香）

## 做法

1. 黄瓜洗净，用刀背**拍裂**成不规则块，再切几刀成入口大小；喜更脆可先冷藏半小时再拌。
2. 小碗中放入蒜末、生抽、香醋、香油、糖、盐，搅匀尝味，调成偏酸鲜的底味。
3. 将料汁倒入黄瓜块，轻拌避免把瓜肉捣太烂；喜辣可加花椒油、干辣椒（或辣椒油）。
4. 装盘后**冷藏 15–30 分钟**再食，风味与脆度往往更佳。

## 小贴士

- 小黄瓜皮嫩可留皮；皮厚或涩时可适度削去部分外皮。
- 万能冰镇腌拌可参考 **盐 : 糖 : 醋 ≈ 1 : 1 : 1**（重量比）作起点，再按口味微调。
