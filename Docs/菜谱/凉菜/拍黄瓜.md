# 拍黄瓜

推荐分类：`凉菜`  
推荐标签：`快手菜`、`家常菜`、`口味/酸辣`、`口味/咸鲜`、`下酒菜`

看似简单，好吃的秘诀在**料汁**和**预处理**：拍裂不规则更吸汁，**杀水**后爽脆、味不易被渗出水分冲淡。

## 一、预处理（关键）

1. **选黄瓜**：**深绿色、带刺、较细的旱黄瓜**（或普通嫩黄瓜），口感最脆。
2. **拍裂**：整根用刀背**拍裂**（不要先切再拍；不规则断面更吸汁），再切成 3～4 厘米小段。
3. **杀水**：黄瓜加**半小勺盐**抓匀，腌 **10 分钟**，倒掉渗出的水。更脆、更入味，拌后不易一出水就变淡。

## 二、料汁（2～3 根黄瓜量）

| 调料 | 用量 | 作用 |
|------|------|------|
| 大蒜 | 4～5 瓣（切末或蒜泥） | 辛香主味 |
| 生抽 | 2 勺 | 咸鲜底味 |
| 香醋 | 2 勺 | 酸爽开胃 |
| 白糖 | 1 小勺 | 提鲜、中和酸辣 |
| 辣椒油 / 油泼辣子 | 1～2 勺 | 香辣（不吃辣可省略） |
| 香油（芝麻油） | 1 勺 | 增香 |
| 盐 | 少许（生抽已有咸味） | 补味 |
| 花椒油 | 半勺（可选） | 麻香层次 |
| 香菜 / 小葱 | 少许 | 点缀 |

**比例口诀**：2 勺生抽 + 2 勺醋 + 1 勺糖 + 足量蒜末 + 辣椒油 + 香油。

## 三、做法

1. **调汁**：小碗放蒜末、生抽、香醋、糖、辣椒油、香油、花椒油（可选），搅匀至糖化开。
2. **混合**：杀好水的黄瓜入大碗，倒入料汁，撒香菜或葱花，拌匀。
3. **爆香升级版（推荐）**：锅烧一小勺油至冒烟，淋在蒜末与辣椒面上激香，再拌匀。
4. **静置**：拌好后静置 **5 分钟**再食，让黄瓜吸汁；**不宜超过约 20 分钟**，以免变软。

## 四、要点小结

- **拍不要只切**：切面太规则，挂汁差。
- **杀水不要省**：直接拌易出水稀释料汁。
- **蒜要足，宜成泥**：刀背拍松再切，或蒜臼轻捣，蒜味更浓。

## 五、变化版料汁（择一）

- **麻酱味**：芝麻酱约 2 勺用温水澥开，加生抽、醋、蒜、辣椒油；口感更厚。
- **柠檬百香果（清爽）**：柠檬汁代醋，加半个百香果、少许蜂蜜；可不放辣油。
- **韩式辣酱味**：韩式辣酱 1 勺 + 醋 1 勺 + 糖半勺 + 蒜末 + 香油。

宜配粥、下饭、解腻。
