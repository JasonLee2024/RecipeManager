# 东北老虎菜

推荐分类：`凉菜`  
推荐标签：`快手菜`、`家常菜`、`口味/香辣`

**地域说明**：东北家常凉菜，黄瓜（常拍碎或切丝）、青椒、香菜与酱、蒜香组合，咸鲜微辣、极下饭。

## 食材

- 旱黄瓜 1–2 根（或普通黄瓜）
- 青椒 1–2 个（切丝）
- 香菜 1 小把（切段）
- 大蒜 3 瓣（切末）
- 小葱 1 根（切葱花，可选）
- 东北大酱或黄豆酱 1–1.5 勺（按咸度调整）
- 生抽 半勺（可选，补鲜）
- 香醋 半勺至 1 勺（可选）
- 植物油 2 勺（浇油用）
- 盐 少许（按酱咸度决定是否再加）

## 做法

1. 黄瓜**拍碎**或切粗丝，与青椒丝、香菜段放在大碗中。
2. 蒜末、葱花（若用）堆在表面；小锅中烧热植物油至微微冒烟。
3. 将热油**浇在蒜末、葱花上**激香，稍凉后加入大酱、生抽、香醋，搅匀后与黄瓜等拌匀。
4. 尝味补盐或补醋；冷藏片刻更入味。

## 小贴士

- 酱咸度差异大，建议**先少放大酱**，拌匀后再补。
- 不喜生酱味可略减酱量，多加香醋与一点糖平衡。
