# 凉拌葛根粉条

推荐分类：`凉菜`  
推荐标签：`快手菜`、`家常菜`、`场景/夏日`、`食材/加工与其他/米面主食/葛根粉条`、`口味/酸辣`

煮熟的葛根粉条过凉水，配黄瓜、胡萝卜丝与酸辣汁，**清爽开胃**，适合夏天。

## 食材

- **葛根粉条**：干约 80～100 g（按包装调整；泡后体积增大）。
- **黄瓜**：半根，切丝。
- **胡萝卜**：小半根，切丝（可焯水 30 秒更易拌）。
- **大蒜**：2～3 瓣，切末。
- **辣椒粉或辣椒油**：适量（按耐辣程度）。
- **香醋**：1.5～2 汤匙。
- **生抽**：1～1.5 汤匙。
- **香油**：1 茶匙。
- **白糖**：1/3 茶匙（提鲜、柔酸）。
- **食盐**：少许。

## 做法

1. **泡发**：葛根粉条温水泡 **10～15 分钟**（或按上文专题建议延长），至可掐断无硬芯，冲洗沥干。
2. **煮粉**：水沸下粉条，煮 **3～5 分钟**（以包装为准），捞出**过凉水**沥干，可淋少许油防粘。
3. **调汁**：碗中混合蒜末、辣椒粉（或辣椒油）、香醋、生抽、香油、糖、盐，搅匀尝味。
4. **拌匀**：与黄瓜丝、胡萝卜丝轻拌装盘；**冷藏 15～30 分钟**再食更入味（可选）。

## 小贴士

- 喜麻可加花椒油；喜鲜可加少量蚝油（偏甜咸口）。
- 粉条勿煮过头，凉拌要保持弹牙。
