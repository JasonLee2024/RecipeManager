# 上海青菜饭

推荐分类：`主食/焖饭`  
推荐标签：`家常菜`、`经典菜`、`沪菜/本帮菜`、`食材/植物/蔬菜/叶菜/上海青`、`食材/植物/谷物与杂粮/大米`、`食材/加工与其他/加工肉制品/香肠`、`口味/咸鲜`

米饭与香肠或咸肉同焖，近熟时拌入**切碎煸炒过的上海青**与猪油，菜香饭润，是**本帮**与江南一带常见的菜饭变体。

## 食材

- **大米**：2～3 人份，按日常煮饭水量略减一丁点（拌菜会带少量油水）。
- **香肠或咸肉**：80～120 g，切丁或薄片。
- **上海青**：300～400 g，洗净**切碎**。
- **猪油**（或植物油）：1～2 汤匙（拌饭增香；无猪油可用植物油代替）。
- **盐**：按咸肉咸度少量或不加。
- **生抽**（可选）：半茶匙，拌菜时提色。

## 做法

1. **煮饭**：大米与香肠或咸肉一起下锅，按电饭煲或砂锅程序煮至**接近熟透**（距完成约 8～10 分钟时进入下一步，可按锅具调整）。
2. **炒青**：另起锅，熔化猪油，大火炒软上海青碎，可淋少许生抽，**盐慎放**。
3. **拌焖**：将炒好的上海青拌入饭中，翻匀后再焖 **3～5 分钟**，使菜香与饭融合。
4. 起锅前用饭勺翻松装盘。

## 小贴士

- 咸肉、香肠偏咸时**不再加盐**；青梗可略切细，更易焖透。
- 用砂锅煮饭时注意底部防焦，拌菜后转小火。
