# 包菜洋葱火腿玉米粒炒粉

主食定位：米粉类快手主食  
推荐分类：`主食/米粉`  
推荐标签：`炒菜`、`快手菜`、`中式家常菜`、`食材/加工与其他/米面主食/米粉`、`食材/加工与其他/加工肉制品`

## 食材准备

- 米粉/粉丝：200g（提前泡软或煮熟沥干）
- 包菜：1/4个（切丝）
- 洋葱：半个（切丝）
- 火腿片：2-3片（切条或丁）
- 玉米粒肠：1-2根（切片）
- 蒜：2瓣（切末）
- 鸡蛋（可选）：1个（打散）

## 调味料

- 生抽 2勺
- 老抽 半勺（上色）
- 蚝油 1勺
- 盐 少许
- 白胡椒粉 少许
- 食用油 适量

## 烹饪步骤

1. 米粉预处理：泡软或煮熟后沥干，拌少许油防粘。
2. 炒配料：先炒鸡蛋盛出；蒜末爆香后下火腿与玉米粒肠煸香。
3. 炒蔬菜：下洋葱炒软，再下包菜大火快炒至断生。
4. 合炒米粉：加入米粉，放生抽、老抽、蚝油快速翻匀。
5. 收尾：回锅鸡蛋，补盐和白胡椒粉，再翻炒 2-3 分钟至干爽略焦香。

## 关键要点

- 大火快炒能保持包菜脆嫩，也更容易形成锅气。
- 米粉提前处理并拌油，可显著降低粘连和结团风险。
- 调味顺序建议先酱油上色，最后再补盐。
