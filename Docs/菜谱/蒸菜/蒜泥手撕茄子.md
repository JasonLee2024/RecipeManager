# 蒜泥手撕茄子

推荐分类：`蒸菜`  
推荐标签：`快手菜`、`经典菜`、`家常菜`

无油烟、偏低脂，蒜香开胃，适合夏天。处理茄子的基础技巧见：`Docs/菜谱/炒菜/茄子省油与经典做法.md`。

## 食材

- 长条茄子 2 根
- 大蒜 1 头（捣成泥，量可偏多）
- 小葱、香菜 适量（切末）
- 小米辣 1～2 根（切圈，可选）
- 生抽 2 勺
- 香醋 1 勺
- 蚝油 1 勺
- 白糖 半勺
- 香油 少许
- 辣椒油 少许（可选）
- 熟白芝麻、熟花生碎 少许（可选）

## 做法

1. 长茄洗净，**整根**入盘；蒸锅水开后**大火蒸 10～15 分钟**，至筷子能轻松扎透（粗细不同时间微调）。
2. 取出**自然晾凉**，或**过凉水**后沥干；**手撕**成条，**轻轻**挤掉多余水（别挤烂）。
3. 小碗放蒜泥、葱花、香菜、小米辣；加生抽、香醋、蚝油、白糖、香油、辣椒油，搅匀成**料汁**（可先少放盐，用蚝油、生抽定咸度）。
4. 料汁浇在茄条上，**抓拌**均匀；撒白芝麻、花生碎更香；冷藏片刻亦可。

## 小贴士

- 手撕比刀切**更易挂汁**、口感更活。
- 喜酸喜辣可在料汁中微调醋与辣椒油比例。
