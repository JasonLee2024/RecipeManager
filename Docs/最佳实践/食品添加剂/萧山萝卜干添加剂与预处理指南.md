# 萧山萝卜干添加剂与预处理指南
> 萧山萝卜干是当地特产，但是商品化包装里面有添加不少的食品添加剂，我们应该如何正确处理这些常见的添加剂的，同时正确的烹饪相关的菜肴？

不必为包装上的添加剂过于焦虑。商业化的萧山萝卜干之所以有它们，主要是为了保鲜、防腐（如苯甲酸钠）和改善风味（如甜蜜素、阿斯巴甜）。只要来源正规，其含量都受到严格国标的管控，是安全的。

掌握些预处理小技巧，就能轻松处理这些物质，让这口地道的江南脆嫩咸鲜，吃得既安全又舒心：

- **清水浸泡**：烹饪前用冷水浸泡30分钟到1小时，可在有效降低咸味的同时，减少添加剂含量（特别是水溶性的防腐剂和甜味剂）。注意中途换水1-2次。
- **温水短时浸泡**：想节省时间，可用40-50℃的温水浸泡20-30分钟，去味效果更好，但注意别用沸水，以免萝卜干口感变软烂。
- **流水冲洗**：浸泡后，在流水下将萝卜干一根根仔细冲洗，特别是褶皱处，能有效带走残留。

然后，就可以让萝卜干变身美味了。很多经典的家常菜，比如**萝卜干炒毛豆**、**剁椒萝卜干煎蛋**，关键都在这“一泡”。炒菜时注意它自带咸味，基本可以不用额外放盐了。你也可以发挥创意，用它来**炒饭**、**炒豆干**或**做馅料**，为家常菜增添独特风味。

希望这些小技巧能让你更安心地享用这份地道风味。
