# ChineseTea（中国茶体系）说明

对应配置文件：`Config/ChineseTea.json`

## 定位

`ChineseTea.json` 用于承载“中国茶体系 + 凉茶草本体系”的具体条目与分类，是一个**独立维度文件**，由 `Config/Beverages.json` 的 `Tea` 分支引用。

## 当前结构

- `ChineseTeaSystem`
  - `凉茶与草本`
  - `绿茶`
  - `红茶`
  - `乌龙茶`
  - `白茶`
  - `黄茶`
  - `黑茶与普洱`
  - `花茶与拼配`
  - `调饮`

## 维护建议

- 尽量避免重复条目（同名不同写法建议通过“别名/同义词”另行维护，而不是直接重复写入列表）。
- 若未来要加入“产地/工艺/季节”等多维属性，建议新增字段结构而不是将注释写进 JSON（JSON 不支持注释）。
