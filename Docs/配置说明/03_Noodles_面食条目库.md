# Noodles（面食条目库）说明

对应配置文件：`Config/Noodles.json`

## 定位

该文件维护“面食/面条菜品名称”的条目库，主要用于：

- 可选字段 `NoodleStyle` 的合法性校验（写入菜谱数据时可启用）
- 后续检索/筛选（按风味分组快速定位）

## 当前分组

- `港粤风味`
- `江浙沪风味`
- `京津鲁风味`
- `川渝黔风味`
- `牛肉面体系`
- `通用拌面体系`

## 维护建议

- 条目尽量保持“菜名”粒度一致（避免把做法、配料、品牌混在一起）。
- 若需要保存“地域/来源/备注（如港式、上海、季节限定）”，建议改为对象数组结构，例如：
  - `{ "Name": "阳春面", "Region": "上海/苏州", "Notes": "..." }`

## 与数据字段的关系

当菜谱对象包含可选字段 `NoodleStyle`（字符串）时，会根据 `Config/Noodles.json` 的全量条目进行校验：

- 合法：`NoodleStyle` 值在任意分组列表中存在（例如 `餐蛋面`）
- 非法：值不在条目库中（会抛出策略违规错误）

建议用法：

- `Category` 仍使用一级分类（例如 `主食`）
- 更细粒度的信息通过 `NoodleStyle` 表达（面食条目库维度）
