## 定位

该文件面向“中餐烹饪工作流”的**备料阶段**，按食材组织结构与含水特性聚类，给出：

- 典型食材
- 风险点
- 推荐预处理动作（可与 `CookingTechniques.json` 的 `Preparation.*` 复用词条）
- 禁忌/谨慎
- 目标质感

它的价值不是替代菜谱，而是提供一套可复用的“备料决策表”。

## 工作流时间线（推荐顺序）

把中餐烹饪视作工作流时，备料阶段建议按如下时间线执行，以减少出水、串味、手忙脚乱与火候失控：

### T-60min ~ T-30min：最慢项先行（解冻/泡发/去盐）

- **冷冻食材**：优先冷藏解冻；临时可流水短解冻；吸干表面水。
- **干货类**：泡发 + 换水 + 去根杂；必要时焯水过凉后沥干。
- **腌腊发酵类**：浸泡脱盐（按盐度决定时长），必要时焯水/蒸软再切配。

目标：把“不可逆的慢过程”提前做完，并让后续切配与烹调更可控。

### T-30min ~ T-15min：处理肉类/水产（码味/上浆/静置）

- **畜肉类**：逆丝切 → 剔筋膜 → 码味 → 上浆/打水吃水 → 静置。
- **禽肉类**：去筋膜 → 切丁/条/块 → 码味 → 上浆/拍粉/拖蛋（按菜式）→ 低温静置。
- **水产类**：去筋膜/剞花刀 → 去腥腌制 → 上浆（蛋清+淀粉）→ 冰镇静置。

目标：用“时间换嫩度”，让后续短时高温处理不至于发柴/出水。

### T-15min ~ T-5min：处理高含水蔬菜（洗净→彻底去水→再切/再撕）

- **叶菜类**：清洗后必须沥/控/吸干；优先手撕分层；尽量避免切得太细。
- **菌菇类**：鲜菇冲洗快洗；泡发类挤水；必要时干煸预脱水。
- **根茎类**：切后易氧化的（如土豆/山药）需要浸泡或尽快下锅；淀粉多可浸泡去淀粉后控干。
- **茄果类**：盐渍短腌/挤水/拍粉/过油等按目标质感选用。

目标：把“出水风险”尽可能在下锅前处理掉，避免炒到一半变成“水煮菜”。

### T-5min ~ T0：分装与排队（上灶前的最后一次组织）

建议把食材按“下锅顺序”分盘：

1. 爆香料（蒜末/姜葱等）
2. 肉类/水产（通常先下，快速定型）
3. 根茎/耐炒蔬菜
4. 叶菜/易出水食材（最后下）
5. 调味料（按工艺分段加入）

目标：上灶后只做“火候与翻锅”，不再做“找东西/补切/补洗”。

## 典型落地：以“炒粉/炒面”为例

- 米粉/面条：提前泡发/煮熟 → 过凉/沥干 → 拌油防粘（必要时）
- 叶菜（包菜）：手撕分层 → 吸干表面水
- 加工肉：切条/丁 → 先煸香
- 合炒：先香料与肉 → 再蔬菜断生 → 最后主食入锅快速翻匀

## 建议与约束

- “推荐预处理”是**动作集合**：不要求全做，按菜式风险点选择组合。
- 若未来要把它接入校验，可作为 `PrepTechniques`/`PrepWorkflow` 维度字段，而不是混入 `Tags`。
- 本文侧重“流程骨架”；涉及温度、时长、KPI 与 CCP 的量化阈值，以增强版文献为准并回填到配置文件。
