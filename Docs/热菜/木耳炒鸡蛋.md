# 木耳炒鸡蛋
这是一道极简却考验细节的家常菜。根据我们之前聊的烹饪工作流逻辑，它的成败核心不在于最后那几下翻炒，而在于对食材（尤其是木耳）的预处理精度。

### 📝 食材准备

| 食材类别 | 推荐用量 | 处理要点 |
| :--- | :--- | :--- |
| **干木耳** | 10-15克 | 选择背后有绒毛、自然卷曲的**秋木耳**口感更脆，用**冷水**泡发2小时。泡好后用手撕成小朵，更易入味。 |
| **鸡蛋** | 2-3个 | 打在碗里加少许盐和**一茶匙水或几滴白醋**搅匀。加水能使鸡蛋更嫩滑。 |
| **调料** | 适量 | 食用油、食盐、少许白糖、白胡椒粉、葱花或蒜末。 |
| **可选配料** | 按需 | 胡萝卜片、黄瓜片、青椒等可丰富色彩和口感。 |

### 🔪 预处理（关键步骤）

1.  **泡发**：木耳用冷水泡发约**2小时**，直到完全变软。
2.  **清洗**：泡好后用手搓洗，去除木耳褶皱里的沙土和杂质。
3.  **沥干**：**务必沥干水分！** 这是避免下锅时炸油的关键。
4.  **焯水**（可选但推荐）：水开后放入木耳，煮约**1-2分钟**捞出。这能让口感更脆，也更安全。
5.  **撕块**：洗净后，用手撕成大小均匀的小朵。

### 🍳 烹饪步骤（分段式烹饪法）

这是做出嫩滑鸡蛋和脆爽木耳的分段式烹饪法：

*   **炒蛋**：热锅凉油，油温五成热（约**150°C**）时倒入蛋液，待边缘凝固后快速划散，约**七分熟**时盛出备用。
*   **炒木耳**：锅中再放少许油，爆香葱花或蒜片。倒入处理好的木耳，中大火翻炒**1-2分钟**，并加入少许盐、糖、白胡椒粉调味。
*   **合炒**：倒入之前炒好的鸡蛋，与木耳快速翻炒均匀。沿锅边淋入少许热水（约1-2汤匙），利用水蒸气让味道迅速融合。
*   **出锅**：所有食材炒匀后即可出锅。出锅前撒上葱花或淋几滴香油增香。

### 💡 关键技巧汇总

*   **如何炒出蓬松嫩滑的鸡蛋？**
    打蛋液时加**一茶匙清水**或几滴白醋，油温控制在**五成热**（约**150°C**），快速划散，**七分熟**就出锅。
*   **如何让木耳口感脆爽？**
    务必**冷水**泡发，泡好后**焯一下水**，下锅前**沥干水分**并**用手撕块**。
*   **怎样调味最鲜美？**
    别依赖蚝油等复合酱料，用**盐、糖、白胡椒粉**就行。盐引出本味，糖中和涩感，胡椒粉提鲜。
*   **如何避免木耳下锅炸油？**
    核心是泡好的木耳必须**彻底沥干水分**。下锅后立刻翻炒，让木耳表面迅速被油包裹。
*   **如何为菜肴增添风味？**
    出锅前沿锅边淋入**几滴香醋**增香解腻，或撒一把**韭菜段**增色提味。

### 💪 营养价值与功效

这道菜富含蛋白质和膳食纤维，木耳中的铁元素和鸡蛋的蛋白质组合，能提高铁的吸收率。木耳的膳食纤维有助于肠道蠕动，两者搭配对心血管健康有益。

### ❓ 常见问答

*   **干木耳需要泡多久？**
    用冷水泡发**2小时**左右即可。长时间泡发会滋生细菌。
*   **木耳需要焯水吗？**
    **建议焯水**，时间**1-2分钟**。这不仅能杀菌，还能让口感更脆，颜色更好看。
*   **可以用新鲜木耳吗？**
    **不建议。** 新鲜木耳含光敏物质，而干木耳在晾晒过程中已被分解，安全性更高。
*   **为什么炒出来的菜会有腥味？**
    通常源于**鸡蛋的蛋腥味**。下次可以在打蛋液时加入**几滴白醋**或**料酒**，能有效去腥增香。
*   **如何让鸡蛋炒出来颜色更金黄？**
    可以只用**蛋黄**来炒。如果不想分离蛋清，可以在打散的蛋液中加入**少许生抽**，也能让成色更诱人。
