# 维护工具说明（Tools）

本目录与仓库根目录 **`Tools/`** 下的 PowerShell 脚本**一一对应**：每个 `Tools/<脚本基名>.ps1` 须有同名 **`Docs/工具说明/<脚本基名>.md`**，并在正文中至少出现一次该基名，供人工查阅与 CI 校验（`Test-ToolsDocsGate.ps1`）。

## 索引

| 脚本 | 说明 |
|------|------|
| `Migrate-RecipesToShardStorage.ps1` | [Migrate-RecipesToShardStorage.md](./Migrate-RecipesToShardStorage.md) |
| `Test-ChangelogGate.ps1` | [Test-ChangelogGate.md](./Test-ChangelogGate.md) |
| `Test-DirectoryNamingGate.ps1` | [Test-DirectoryNamingGate.md](./Test-DirectoryNamingGate.md) |
| `Test-ToolsDocsGate.ps1` | [Test-ToolsDocsGate.md](./Test-ToolsDocsGate.md) |

## 新增脚本时

1. 在 `Tools/` 添加 `.ps1`。
2. 在本目录新增同名 `.md`（可先用脚本内 `.SYNOPSIS` / `.DESCRIPTION` 扩写）。
3. 更新上表；推送后 CI 中的 **Tools 说明文档门禁** 会校验对应关系。
